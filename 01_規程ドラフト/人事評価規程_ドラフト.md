# 人事評価規程（ドラフト）

会社名：株式会社MoMo

施行日：YYYY年MM月DD日

## 第1章　総則

### 第1条（目的）

本規程は、株式会社MoMo（以下「当社」という。）の従業員の人事評価に関する基本事項を定める。

2. 人事評価は、従業員の一定期間の業務成果、職務遂行能力及び行動を公正に評価し、昇給、賞与、配置、昇格、教育訓練その他人事管理へ適切に反映することにより、従業員の成長、組織力の向上及び経営目標の達成を図ることを目的とする。

3. 本規程は、就業規則、賃金規程その他社労士レビュー済みの既存労務規程と整合するよう運用し、差異がある場合は、社労士確認のうえ必要な改定を行う。

### 第2条（適用範囲）

本規程は、当社の正社員に適用する。

2. 次の各号に該当する者については、会社が別に定める場合を除き、人事評価の対象外又は個別評価とすることができる。

1. 評価対象期間における勤務期間が6か月に満たない者
2. 評価期日において休職中の者
3. 試用期間中の者
4. パートタイマー、アルバイト、業務委託その他雇用形態又は契約形態が異なる者
5. 出向者その他会社が通常の評価が困難と認める者

## 第2章　評価

### 第3条（評価の時期及び期間）

人事評価は、原則として毎年2回、7月及び1月に実施する。

2. 評価対象期間は、次のとおりとする。

| 評価実施月 | 評価対象期間 |
| --- | --- |
| 7月 | 1月1日から6月30日まで |
| 1月 | 7月1日から12月31日まで |

3. 会社は、事業年度、組織変更、評価制度の改定その他必要がある場合、評価実施時期又は評価対象期間を変更することができる。

### 第4条（評価要素及び評価項目）

人事評価は、被評価者ごとに、次の評価要素により行う。

1. 業務成果：担当業務、目標、案件、売上、開発、運用、顧客対応その他職務上の成果
2. 職務遂行能力：専門性、課題解決力、実行力、品質管理、業務改善、再現性のある業務遂行力
3. 行動評価：バリュー体現、協働、主体性、誠実性、報告連絡相談、コンプライアンス意識
4. マネジメント評価：部門運営、メンバー育成、数値管理、リスク管理その他管理職又は責任者に必要な事項

2. 具体的な評価項目、評価ウェイト及び評価表は、会社が別に定める。

### 第5条（評価表）

人事評価は、職種、役割、等級又は職責に応じた評価表により行う。

2. 評価表には、評価対象期間、目標、評価項目、自己評価、一次評価、二次評価、総合評価、評価コメント及びフィードバック内容を記載する。

3. 評価表は、Notion、Googleスプレッドシートその他会社が指定する方法により作成、提出及び保存することができる。

## 第3章　評価の実施

### 第6条（実施方法）

人事評価は、原則として、自己評価、一次評価及び二次評価の3段階により行う。

2. 自己評価は被評価者自身が行い、一次評価及び二次評価は所定の評価者が、評価対象期間における事実、成果、行動及び職務遂行状況に基づき行う。

3. 会社は、組織規模又は職責に応じて、一次評価のみ又は代表取締役社長による最終確認とすることができる。

### 第7条（評価者）

評価者は、被評価者を指導監督する立場にある者を原則とする。

2. 評価者は、次の区分を初期基準とする。

| 被評価者 | 一次評価者 | 二次評価者・最終決定者 |
| --- | --- | --- |
| 部門責任者 | 代表取締役社長又は担当取締役 | 代表取締役社長 |
| 一般従業員 | 所属部門責任者 | 代表取締役社長又は管理部門責任者 |
| 管理部門所属者 | 管理部門責任者 | 代表取締役社長 |

3. 評価者が評価対象期間中に着任して間もない場合、兼務関係がある場合、又は評価者として適当でない事情がある場合、会社は別の評価者を指定することができる。

### 第8条（自己評価）

被評価者は、会社が指定する評価表により、評価対象期間における目標達成状況、成果、行動、課題及び次期目標を自己評価として記載する。

### 第9条（評価区分）

評価区分は、原則として次の5段階とする。

| 評価 | 内容 |
| --- | --- |
| S | 期待水準を大きく上回り、極めて優れている |
| A | 期待水準を上回り、優れている |
| B | 期待水準を満たしている |
| C | 期待水準に一部達していない |
| D | 期待水準を大きく下回り、改善を要する |

### 第10条（評価者の遵守事項）

評価者は、評価を行うにあたり、次の事項を遵守しなければならない。

1. 評価表に定められた評価対象項目に基づいて評価すること
2. 評価対象期間における事実、成果、行動及び信頼できる報告に基づいて公正に評価すること
3. 個人的な感情、先入観、印象又は評価対象期間外の事情に過度に左右されないこと
4. 被評価者から評価理由の説明を求められた場合に、合理的に説明できる評価を行うこと
5. 評価に関する情報を適切に管理し、正当な理由なく第三者に開示しないこと

### 第11条（調整）

二次評価者又は代表取締役社長は、評価者間又は部門間で評価に著しい不均衡があると認める場合、必要な調整を行うことができる。

2. 管理部は、評価結果の分布、評価コメント、昇給及び賞与への反映状況を確認し、必要に応じて評価者に再確認を求める。

### 第12条（決定）

評価結果は、一次評価、二次評価及び必要な調整を経たうえで、代表取締役社長が最終決定する。

2. 評価結果を昇給、賞与、昇格、配置その他人事上の処遇へ反映する場合は、賃金規程、職務権限規程及び稟議規程に従い、必要な承認を得る。

## 第4章　評価結果の取扱い

### 第13条（評価結果の効力）

評価結果は、次回の評価結果が決定されるまで、当該従業員の総合的な勤務成績を示すものとして効力を有する。

### 第14条（評価結果の使途）

評価結果は、従業員の昇給、賞与、昇格、配置、教育訓練、目標設定及び職務分担の見直しに反映することができる。

2. 昇給は、賃金規程に基づき、原則として毎年4月1日に行う賃金改定において、会社業績、勤務成績その他必要な事情とあわせて総合的に判断する。

3. 賞与は、賃金規程に基づき、原則として5月、9月及び1月の支給時に、会社業績、部門業績、個人の評価結果、出勤状況、貢献度、役割及び職務内容を総合的に勘案して判断する。

4. 評価結果は、会社業績、部門業績、職務内容、雇用契約、賃金規程その他会社が必要と認める事情とあわせて総合的に判断する。

### 第15条（評価結果の開示及びフィードバック）

評価結果は、被評価者本人に開示し、評価者又は会社が指定する者が必要な説明及びフィードバックを行う。

2. フィードバックでは、評価結果、評価理由、次期に期待する役割、改善点及び成長課題を可能な限り具体的に伝える。

### 第16条（異議申立て）

被評価者は、評価結果に異議がある場合、評価結果の開示日から3営業日以内に、管理部に異議申立てを行うことができる。

2. 会社は、異議申立てを受けた場合、評価者、被評価者及び関係者への確認を行い、必要があると認めるときは評価結果を見直す。

3. 異議申立てに対する最終判断は、代表取締役社長が行う。

## 第5章　雑則

### 第17条（評価者訓練）

会社は、人事評価の公正性及び納得性を確保するため、必要に応じて評価者に対する説明、研修又は評価基準の共有を行う。

### 第18条（評価資料の保存）

評価表、評価結果、フィードバック記録、異議申立て記録その他人事評価に関する資料は、管理部が保存管理する。

2. 評価資料の保存期間は、原則として3年とする。ただし、上場準備、労務紛争対応、法令対応その他会社が必要と認める場合は、必要な期間保存することができる。

### 第19条（改廃）

本規程の改廃は、規程管理規程に基づき、取締役会の決議により行う。

## 要確認事項

- 既存の社労士レビュー済み就業規則・人事評価関連規程との条文整合
- 評価表の具体項目、評価ウェイト、等級制度の有無
- 半期評価と、就業規則上の年3回賞与（5月、9月、1月）の算定期間との連動方法
- 評価結果の昇給、賞与、昇格への具体的な反映方法
- 評価資料の保存場所（Notion、Google Drive、労務管理システム等）
