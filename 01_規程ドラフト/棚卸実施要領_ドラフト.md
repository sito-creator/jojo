# 棚卸実施要領（ドラフト）

会社名：株式会社MoMo

施行日：YYYY年MM月DD日

## 第1章　総則

### 第1条（目的）

本要領は、株式会社MoMo（以下「当社」という。）の棚卸資産管理規程に基づき、棚卸資産の実地棚卸を適切に実施するための手順、役割、記録、差異処理及び報告方法を定めることを目的とする。

### 第2条（適用範囲）

本要領は、当社が棚卸資産を保有する場合に実施する実地棚卸に適用する。

2. 当社が棚卸資産を保有しない期間においては、管理部が棚卸資産の有無確認を行い、その結果を記録する。

3. 固定資産、貸与端末、ソフトウェア、ライセンスその他固定資産管理規程により管理する資産の現品確認は、固定資産管理規程に従う。ただし、棚卸資産との区分が不明な場合、管理部が会計処理方針を確認する。

### 第3条（棚卸対象）

棚卸対象は、棚卸資産管理規程に定める棚卸資産とする。

2. 棚卸対象となる可能性があるものは、販売用又は有償提供用の教材、冊子、端末、販促物、制作物、仕掛品、販売用ライセンス、納品前成果物その他管理部が指定するものとする。

### 第4条（実施時期）

実地棚卸は、棚卸資産を保有する場合、原則として会計年度末に実施する。

2. 管理部が必要と認める場合、四半期末、月末、事業終了時、重要な案件終了時、担当者変更時、移転時又は棚卸資産の紛失等が疑われる時点で臨時棚卸を実施することができる。

## 第2章　棚卸計画

### 第5条（棚卸責任者）

管理部は、棚卸実施にあたり、棚卸責任者を定める。

2. 棚卸責任者は、棚卸計画の作成、棚卸担当者の指定、棚卸表の準備、実地棚卸の管理、差異調査、報告書作成及び記録保存を行う。

### 第6条（棚卸担当者）

棚卸担当者は、棚卸責任者の指示に従い、棚卸対象の数量、状態、保管場所、管理番号その他必要事項を確認する。

2. 棚卸対象を日常的に管理する担当者のみで棚卸を完結させず、可能な範囲で管理部又は別担当者が確認に関与する。

### 第7条（棚卸計画）

棚卸責任者は、棚卸実施前に、次の事項を定めた棚卸計画を作成する。

1. 棚卸実施日及び実施時間
2. 棚卸対象及び保管場所
3. 棚卸責任者及び棚卸担当者
4. 棚卸表、台帳、証憑その他使用資料
5. 棚卸手順、確認方法及び差異報告方法
6. 棚卸中の入出庫、販売、配布又は移動の取扱い

2. 棚卸計画は、Notion、Google Driveその他会社が指定する方法により保存する。

### 第8条（棚卸前準備）

棚卸担当部門は、棚卸実施前に、棚卸対象を整理し、品目、数量、保管場所及び管理番号を確認できる状態にしなければならない。

2. 棚卸実施前後に入出庫、販売、配布、廃棄又は移動がある場合、担当部門は、日付、数量及び理由を明確に記録する。

3. 棚卸対象に個人情報、顧客情報、ソースコード、AI関連データその他秘密情報が含まれる場合、情報セキュリティ管理規程及び個人情報保護規程に従い、アクセス権限及び取扱方法を確認する。

## 第3章　実地棚卸

### 第9条（棚卸方法）

棚卸担当者は、棚卸対象について、現物確認、台帳照合、数量確認、状態確認及び保管場所確認を行う。

2. 棚卸数量は、目視、数量カウント、管理番号確認、ファイル又はライセンス情報の照合その他対象資産の性質に応じた合理的な方法により確認する。

3. 納品前成果物、制作途中コンテンツ、開発中プロダクトその他物理的な数量確認が困難なものは、契約、作業記録、納品予定、進捗資料、リポジトリ、Notion、Google Driveその他証跡により確認する。

### 第10条（棚卸表）

棚卸担当者は、棚卸表に次の事項を記録する。

1. 棚卸実施日
2. 品目名、管理番号及び区分
3. 帳簿数量及び実地数量
4. 保管場所及び状態
5. 差異の有無及び内容
6. 棚卸担当者及び確認者
7. 備考

2. 棚卸表は、棚卸責任者が回収し、棚卸資産台帳と照合する。

### 第11条（棚卸中の入出庫制限）

棚卸中は、原則として棚卸対象の入庫、出庫、販売、配布、移動又は廃棄を停止する。

2. 業務上やむを得ず入出庫等を行う場合、担当者は、棚卸責任者の承認を得たうえで、入出庫日、数量、理由及び相手先を記録する。

## 第4章　差異処理

### 第12条（差異確認）

棚卸責任者は、棚卸表と棚卸資産台帳を照合し、差異がある場合、担当部門と連携して原因を調査する。

2. 差異原因は、入力誤り、入出庫記録漏れ、販売又は配布記録漏れ、保管場所変更、破損、紛失、盗難、廃棄未記録、評価減漏れその他合理的に分類して記録する。

### 第13条（差異修正）

棚卸差異を修正する場合、棚卸責任者は、差異内容、原因、修正方法、会計処理、再発防止策及び承認者を記録する。

2. 重要な差異、紛失、盗難、不正利用又は情報漏えいのおそれがある場合、棚卸責任者は、管理部、代表取締役社長及び必要に応じて経営会議へ報告する。

3. 財務報告又は上場準備上重要な差異については、取締役会へ報告又は付議する。

### 第14条（評価減及び廃棄）

棚卸の結果、陳腐化、破損、劣化、販売見込み低下、契約キャンセルその他の理由により評価減又は廃棄が必要と判断される場合、棚卸責任者は、棚卸資産管理規程に従い必要な承認を得る。

2. 廃棄を行う場合、廃棄日、品目、数量、理由、廃棄方法、情報消去の要否及び証跡を記録する。

## 第5章　報告及び保存

### 第15条（棚卸報告書）

棚卸責任者は、実地棚卸終了後、棚卸報告書を作成し、管理部及び代表取締役社長へ報告する。

2. 棚卸報告書には、次の事項を記載する。

1. 棚卸実施日及び対象範囲
2. 棚卸担当者及び確認者
3. 棚卸結果の概要
4. 棚卸差異及び原因
5. 評価減、廃棄又は修正処理の内容
6. 再発防止策又は改善事項
7. 経営会議又は取締役会への報告要否

### 第16条（棚卸資産なしの確認）

当社が棚卸資産を保有しない期間においては、管理部は、会計年度末に各部門へ棚卸資産の有無を確認する。

2. 前項の確認は、Notion、Googleフォーム、メール、Googleスプレッドシートその他会社が指定する方法により行う。

3. 棚卸資産なしと判断した場合でも、確認日、確認対象部門、確認者及び判断理由を記録し、保存する。

### 第17条（記録の保存）

棚卸計画、棚卸表、棚卸報告書、差異調査、修正記録、廃棄記録、棚卸資産なしの確認記録その他実地棚卸に関する資料は、Notion、Google Driveその他会社が指定する方法により保存する。

2. 前項の資料の保存期間は、原則として10年とする。

### 第18条（改廃）

本要領の改廃は、棚卸資産管理規程及び規程管理規程に基づき、取締役会の決議により行う。
