# 執行役員規程（ドラフト）

会社名：株式会社MoMo

施行日：YYYY年MM月DD日

## 第1章　総則

### 第1条（目的）

本規程は、株式会社MoMo（以下「当社」という。）における執行役員制度を導入する場合の、執行役員の選任、職務、権限、任期、報酬、契約及び解任に関する基本事項を定め、業務執行体制の明確化及び経営管理の強化を図ることを目的とする。

2. 当社が執行役員を置かない期間においては、本規程は将来導入時の準則として管理し、執行役員に関する職務は、代表取締役社長、担当取締役又は会社が指定する者が担う。

### 第2条（執行役員の位置付け）

執行役員は、取締役会又は代表取締役社長の指揮監督のもと、当社の特定の業務、部門又は事業を担当し、業務執行を担う者をいう。

2. 執行役員は、会社法上の機関又は役員ではなく、当社が業務執行上の必要に応じて任命する社内の役職である。

3. 執行役員が取締役を兼務する場合を除き、執行役員であることをもって取締役会の構成員となるものではない。

### 第3条（適用範囲）

本規程は、当社が選任する執行役員に適用する。

2. 執行役員が従業員の地位を有する場合、雇用契約、就業規則、賃金規程その他当社の労務関連規程をあわせて適用する。

3. 執行役員が委任契約、業務委託契約その他雇用契約以外の契約により職務を遂行する場合、個別契約の定めを優先し、本規程は当該契約に反しない範囲で適用する。

### 第4条（他規程との関係）

執行役員の職務遂行に関しては、本規程のほか、取締役会規程、経営会議規程、組織規程、業務分掌規程、職務権限規程、稟議規程、予算管理規程、リスク・コンプライアンス管理規程その他当社の規程を適用する。

2. 本規程と他の規程又は個別契約の内容に差異がある場合、法令に反しない範囲で、取締役会が定める方針又は個別契約の定めを踏まえて解釈する。

## 第2章　選任及び任期

### 第5条（選任）

執行役員は、当社の事業運営上の必要性、担当業務の重要性、候補者の経験、能力、実績、コンプライアンス意識及び上場準備会社として求められる管理水準を踏まえ、取締役会の決議により選任する。

2. 取締役会が設置されるまでの期間又は緊急に選任が必要な場合は、代表取締役社長が候補者を決定し、経営会議へ報告する。ただし、取締役会設置後は、速やかに取締役会の承認を得るものとする。

### 第6条（選任手続）

執行役員の候補者を選定する場合、管理部は、候補者の経歴、担当予定業務、雇用又は契約形態、報酬条件、兼職状況、利益相反の有無及び反社会的勢力との関係の有無を確認する。

2. 前項の確認結果は、Notion、Google Driveその他会社が指定する方法により記録し、取締役会又は経営会議の資料として保存する。

### 第7条（任期）

執行役員の任期は、原則として1年とし、選任後最初に到来する事業年度末又は取締役会が定める日までとする。

2. 執行役員は、再任を妨げない。

3. 任期中であっても、組織変更、担当業務の変更、本人の退職、契約終了その他会社が必要と認める場合、取締役会の決議により任期を変更し、又は終了させることができる。

### 第8条（契約）

執行役員が従業員として職務を遂行する場合、当社は、雇用契約書、労働条件通知書、辞令又はこれに準ずる書面若しくは電子的方法により、担当業務、役職、報酬、任期、権限、秘密保持義務その他必要事項を明示する。

2. 執行役員が雇用契約以外の契約により職務を遂行する場合、当社は、委任契約書、業務委託契約書その他個別契約により必要事項を定める。

## 第3章　職務及び権限

### 第9条（職務）

執行役員は、取締役会、代表取締役社長又は担当取締役の指示に基づき、次の職務を行う。

1. 担当部門又は担当事業の業務執行
2. 事業計画、予算及びKPIの立案、実行及び進捗管理
3. 担当領域の人員、外注先、システム、契約及びコストの管理
4. 担当領域に係るリスク、コンプライアンス、情報セキュリティ及び個人情報保護の管理
5. 経営会議、取締役会又は代表取締役社長への報告
6. その他会社が命じる業務

### 第10条（権限）

執行役員の権限は、職務権限規程、稟議規程、取締役会決議、代表取締役社長の指示又は個別の辞令により定める。

2. 執行役員は、自己の権限を超える事項について、事前に必要な承認又は決議を得なければならない。

3. 執行役員は、取締役会決議事項、重要な契約、重要な投資、予算外支出、関連当事者取引、利益相反取引、重要な人事、重要なリスクその他当社の経営に重大な影響を及ぼす事項について、独断で決定してはならない。

### 第11条（報告義務）

執行役員は、担当業務の状況、予算実績、KPI、重要案件、重要な契約、採用、外注、リスク、クレーム、情報セキュリティ事故その他会社が必要と認める事項について、経営会議又は代表取締役社長へ定期的に報告しなければならない。

2. 前項のうち、取締役会付議事項又は報告事項に該当するものは、取締役会規程、職務権限規程及び稟議規程に従い、取締役会へ付議又は報告する。

### 第12条（会議への出席）

執行役員は、代表取締役社長又は取締役会が必要と認める場合、経営会議、取締役会その他会社が指定する会議に出席し、担当業務に関する説明又は報告を行う。

2. 執行役員が取締役を兼務しない場合、取締役会へ出席しても議決権を有しない。

## 第4章　報酬及び評価

### 第13条（報酬）

執行役員の報酬は、雇用契約、労働条件通知書、個別契約又は取締役会決議により定める。

2. 執行役員が従業員の地位を有する場合、報酬、賞与、手当、社会保険、源泉徴収その他労務上の取扱いは、就業規則、賃金規程及び個別の労働条件に従う。

3. 執行役員が取締役を兼務する場合、取締役報酬と従業員給与又は執行役員報酬の区分を明確にし、法令、税務及び会計上必要な確認を行う。

### 第14条（評価）

執行役員の評価は、担当業務の成果、事業計画及び予算の達成状況、組織運営、リスク管理、コンプライアンス、部門横断の協力度、上場準備への貢献その他会社が必要と認める事項を総合して行う。

2. 評価結果は、再任、担当変更、報酬改定、契約更新その他人事上の判断に反映することができる。

## 第5章　義務及び禁止事項

### 第15条（善管注意義務等）

執行役員は、会社から委ねられた職務を誠実に遂行し、法令、定款、社内規程、取締役会決議、代表取締役社長の指示及び個別契約を遵守しなければならない。

### 第16条（秘密保持及び情報管理）

執行役員は、在任中及び退任後においても、職務上知り得た営業秘密、個人情報、顧客情報、技術情報、ソースコード、AI関連データ、上場準備情報その他会社が秘密として管理する情報を、会社の許可なく第三者に開示し、又は業務外に利用してはならない。

2. 執行役員は、情報セキュリティ管理規程、個人情報保護規程及び文書管理規程を遵守し、担当領域における情報管理を徹底しなければならない。

### 第17条（競業及び利益相反）

執行役員は、会社の承認なく、当社と競合する事業を営み、又は第三者のために当社と競合する業務に従事してはならない。

2. 執行役員は、自己又は第三者の利益と当社の利益が相反するおそれがある場合、速やかに会社へ申告し、必要な承認を得なければならない。

3. 関連当事者取引に該当する可能性がある取引については、関連当事者取引管理規程に従う。

### 第18条（禁止事項）

執行役員は、次の行為を行ってはならない。

1. 権限を超える契約、支出、採用、外注又は投資
2. 虚偽報告、重要事実の隠蔽又は証跡の改ざん
3. 会社資産、情報資産又は取引先情報の私的利用
4. ハラスメント、差別、反社会的勢力との関係構築その他会社の信用を害する行為
5. 法令、定款、社内規程又は個別契約に違反する行為

## 第6章　退任及び解任

### 第19条（退任）

執行役員は、任期満了、辞任、退職、契約終了、死亡その他会社が定める事由により退任する。

2. 執行役員が辞任しようとする場合、原則として1か月前までに会社へ申し出るものとする。ただし、個別契約に別段の定めがある場合は、当該定めに従う。

### 第20条（解任又は担当変更）

会社は、次の各号のいずれかに該当する場合、取締役会の決議により、執行役員を解任し、又は担当業務を変更することができる。

1. 職務遂行能力、業績又は適格性に重大な問題がある場合
2. 法令、定款、社内規程、取締役会決議、代表取締役社長の指示又は個別契約に違反した場合
3. 会社の信用を害し、又は会社に損害を与えた場合
4. 心身の故障その他の事情により職務遂行が困難となった場合
5. 組織変更、事業方針の変更その他会社が必要と認める場合

2. 執行役員が従業員の地位を有する場合、解任又は担当変更は、雇用契約上の地位を当然に終了させるものではなく、就業規則、労働契約及び法令に従い必要な手続を行う。

### 第21条（引継ぎ及び返却）

執行役員が退任し、又は担当業務を変更する場合、会社の指示に従い、担当業務、契約、取引先、予算、リスク、権限、資料、アカウントその他必要事項を速やかに引き継がなければならない。

2. 執行役員は、会社から貸与又は付与された端末、資料、アカウント、権限、秘密情報その他会社資産を速やかに返却し、又は会社の指示に従い削除しなければならない。

## 第7章　雑則

### 第22条（記録及び保存）

執行役員の選任、任期、契約、担当業務、権限、報酬、評価、退任、解任、担当変更その他執行役員に関する記録は、Notion、Google Driveその他会社が指定する方法により保存する。

2. 前項の記録の保存期間は、原則として10年とする。

### 第23条（改廃）

本規程の改廃は、規程管理規程に基づき、取締役会の決議により行う。
