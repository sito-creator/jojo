# 出張・旅費規程（ドラフト）

会社名：株式会社MoMo

施行日：YYYY年MM月DD日

## 第1章　総則

### 第1条（目的）

本規程は、株式会社MoMo（以下「当社」という。）の役員及び社員が業務のため出張する場合の手続、旅費の支給、精算及び証憑管理に関する事項を定めることを目的とする。

2. 本規程は、就業規則、賃金規程、職務権限規程、稟議規程、経費精算に関する社内ルール及びマネーフォワードの運用と整合するよう運用する。

### 第2条（適用範囲）

本規程は、当社の役員及び就業規則に定める社員に適用する。

2. パートタイマー、契約社員、業務委託者その他雇用形態又は契約形態が異なる者については、個別契約、業務委託契約、発注条件又は会社が別に定めるところによる。

### 第3条（出張の定義）

本規程における出張とは、業務上の必要により、通常勤務地又は自宅を起点として、目的地まで片道100km以上の場所へ移動し、職務を遂行することをいう。

2. 前項にかかわらず、片道100km未満であっても、移動時間、業務内容、宿泊の要否その他事情を踏まえ、会社が出張として取り扱うことが適当と認める場合は、本規程を適用する。

### 第4条（出張の区分）

出張の区分は、次のとおりとする。

1. 日帰り出張：片道100km以上又は片道2時間以上を要する地域への出張であり、当日中に帰着するもの
2. 宿泊出張：日帰り出張以外で、業務上宿泊を要するもの
3. 海外出張：国外への出張
4. その他会社が出張として認めるもの

### 第5条（旅費の種類）

本規程における旅費は、次のものをいう。

1. 交通費
2. 宿泊費
3. 日当
4. その他会社が業務上必要と認める費用

2. 交通費、宿泊費その他実費精算とする費用は、領収書、利用明細、予約確認書、請求書その他支払内容を確認できる証憑に基づき支給する。

### 第6条（利用交通機関）

利用する交通機関は、鉄道、航空機、船舶、バスその他合理的な公共交通機関を原則とする。

2. タクシー、レンタカー、カーシェア、自家用車その他公共交通機関以外の手段は、業務上必要がある場合又はやむを得ない事情がある場合に限り、事前に承認を得て利用することができる。

3. グリーン車、プレミアムクラス、ビジネスクラスその他通常料金を超える座席又はサービスは、代表取締役社長又は会社が指定する承認者の事前承認を得た場合に限り利用することができる。

## 第2章　出張手続

### 第7条（出張の申請）

出張を行う者は、出張前に、出張目的、訪問先、日程、概算費用、利用交通機関、宿泊予定及び同行者を明らかにし、会社が指定する方法により申請し、承認を受けなければならない。

2. 出張申請は、Notion、マネーフォワード、Googleフォーム、稟議ページその他会社が指定する方法により行うことができる。

3. 出張費用が職務権限規程又は稟議規程に定める承認基準に該当する場合、出張申請に加えて、必要な稟議又は承認を取得する。

### 第8条（承認者）

出張の承認者は、原則として所属部門責任者とする。

2. 部門責任者の出張、役員の出張、海外出張、宿泊費上限を超える出張その他重要な出張については、代表取締役社長又は会社が指定する者の承認を得る。

3. 承認者は、出張の必要性、日程、費用、訪問目的及び業務上の合理性を確認する。

### 第9条（予定の変更）

出張中に、予定していた経路、日程、宿泊先、訪問先又は費用を変更する必要が生じた場合、出張者は、速やかに承認者へ連絡し、承認を受けなければならない。

2. 緊急その他やむを得ない事情により事前承認を受けることができない場合、出張者は、帰着後速やかに変更理由を報告し、事後承認を受ける。

### 第10条（旅費の仮払い）

会社は、出張申請に基づき、必要があると認める場合、旅費の概算額を仮払いすることができる。

2. 仮払いを受けた者は、出張終了後速やかに精算し、未使用額がある場合は会社へ返還しなければならない。

### 第11条（出張報告及び旅費精算）

出張者は、出張終了後、原則として5営業日以内に、出張結果、訪問先、業務内容、成果、旅費明細及び証憑を会社が指定する方法により提出し、旅費精算を行わなければならない。

2. 旅費精算は、原則としてマネーフォワードを利用して行う。

3. 領収書、利用明細、予約確認書その他証憑は、マネーフォワードへの添付又は会社が指定する方法により保存する。

4. 出張者が正当な理由なく精算を遅延した場合、会社は、旅費の支給又は仮払金の追加支給を留保することができる。

## 第3章　出張旅費

### 第12条（交通費）

交通費は、業務上合理的な経路及び方法による実費を支給する。

2. 鉄道料金は、普通車指定席又は自由席を原則とする。

3. 航空料金は、エコノミークラス又はこれに相当する座席を原則とする。

4. タクシー、レンタカー、カーシェア、自家用車、有料道路、駐車場その他通常の公共交通機関以外の費用は、業務上の必要性及び合理性が確認できる場合に限り支給する。

### 第13条（宿泊費）

宿泊費は、宿泊日数に応じ、実費を支給する。

2. 国内出張における宿泊費の1泊当たり上限額は、次のとおりとする。

| 区分 | 宿泊費上限額 |
| --- | --- |
| 一般社員 | 12,000円 |
| 部門責任者 | 15,000円 |
| 役員 | 20,000円 |

3. 業務上の都合、繁忙期、開催地の宿泊事情、安全確保その他やむを得ない事情により前項の上限額を超える場合、事前に承認を得たときは、その実費を支給することができる。

4. 宿泊先は、安全性、交通利便性、業務上の必要性及び経済性を考慮して選定する。

### 第14条（日当）

日当は、原則として支給しない。

2. 前項にかかわらず、長時間移動、海外出張、会社イベント、研修登壇その他会社が必要と認める場合、事前承認により日当を支給することができる。

3. 日当を支給する場合の金額、対象者、対象日数及び支給条件は、出張内容に応じて個別に定める。

### 第15条（海外出張）

海外出張を行う場合、出張者は、渡航先、渡航目的、日程、航空券、宿泊先、概算費用、保険、ビザその他必要事項について、事前に代表取締役社長又は会社が指定する承認者の承認を得なければならない。

2. 海外出張に係る航空券、宿泊費、現地交通費、通信費、海外旅行保険その他必要費用は、業務上必要かつ合理的な範囲で実費を支給する。

3. 海外出張の日当、為替換算、証憑保存その他詳細は、出張内容に応じて個別に定める。

### 第16条（同行者を伴う出張）

取引先、上位職者、役員その他同行者の都合により、通常の基準と異なる交通機関、宿泊先又は費用が必要となる場合、事前承認を得たときは、同行者との均衡を踏まえて旅費を支給することができる。

2. 取引先、主催者その他第三者が旅費の全部又は一部を負担する場合、会社は、重複して旅費を支給しない。

### 第17条（出張中の事故等）

出張中に、負傷、疾病、天災、交通機関の遅延又は停止、その他やむを得ない事情により予定日程を超えて滞在する必要が生じた場合、出張者は、速やかに会社へ報告し、必要な指示を受ける。

2. 前項の場合、会社が業務上必要かつ合理的と認める交通費、宿泊費その他費用について、実費を支給することができる。

## 第4章　赴任旅費

### 第18条（赴任旅費）

転勤、配置転換、長期出向その他会社の命令により勤務地又は居住地を変更する必要がある場合、会社は、必要に応じて赴任旅費を支給することができる。

2. 赴任旅費の支給対象、支給範囲、上限額、家族同伴の取扱い、荷造運送費その他詳細は、事前に会社が個別に決定する。

3. 赴任旅費を支給する場合、対象者は、見積書、領収書、請求書その他証憑を提出し、会社が指定する方法により精算しなければならない。

## 第5章　雑則

### 第19条（不正又は不適切な精算）

虚偽の申請、私的利用、重複精算、証憑の改ざん、会社の承認を得ない高額利用その他不正又は不適切な旅費精算を行ってはならない。

2. 会社は、不正又は不適切な旅費精算が判明した場合、旅費の不支給、返還請求、懲戒その他必要な措置を講じることができる。

### 第20条（保存）

出張申請、承認記録、旅費精算、証憑、出張報告その他出張に関する資料は、マネーフォワード、Notion、Google Driveその他会社が指定する方法により保存する。

2. 出張及び旅費精算に関する資料の保存期間は、原則として10年とする。

### 第21条（改廃）

本規程の改廃は、規程管理規程に基づき、取締役会の決議により行う。

## 要確認事項

- 出張申請の具体的な運用ツール（Notion、マネーフォワード、Googleフォーム等）
- 出張精算期限を5営業日以内でよいか
- 宿泊費上限額（一般社員12,000円、部門責任者15,000円、役員20,000円）でよいか
- 日当は原則不支給でよいか
- 海外出張の想定有無
- タクシー、レンタカー、カーシェア、自家用車利用の承認ルール
- 赴任旅費規定を当面簡素運用でよいか
