# 販売管理規程（ドラフト）

会社名：株式会社MoMo

施行日：YYYY年MM月DD日

## 第1章　総則

### 第1条（目的）

本規程は、株式会社MoMo（以下「当社」という。）の受注、見積、契約、請求、代金回収、債権管理その他販売活動に関する基本事項を明確にし、販売取引の適正性、効率性及び収益管理の正確性を確保することを目的とする。

### 第2条（適用範囲）

本規程は、販売に関わる取引業務全般を行うすべての部署及び役職員に適用する。

2. 本規程に定めのない販売取引に関する手続は、職務権限規程、稟議規程、経理規程、与信管理規程、反社会的勢力対応規程、個人情報保護基本規程、情報セキュリティ規程その他関連規程に従う。

### 第3条（基本方針）

販売取引は、取引先、取引内容、金額、契約条件、提供内容、請求条件、回収条件、情報管理上の留意事項及びリスクを明確にしたうえで実施する。

2. 販売取引に関する証憑、承認履歴、契約書、請求書及び入金記録は、事後確認ができるよう保存する。

## 第2章　取引先管理

### 第4条（取引先情報の管理）

取引先情報は、原則としてNotionで管理する。

2. 取引先情報には、会社名、担当者、連絡先、取引内容、契約状況、請求先、支払条件、入金状況、与信確認状況、反社チェック状況、個人情報又は機密情報の取扱いその他必要な情報を記録する。

### 第5条（反社会的勢力該当性の確認）

引合い又は新規取引を開始する場合、担当部門は、過去の取引実績及び取引先情報を確認したうえで、反社会的勢力対応規程に従い、反社会的勢力該当性の確認を行う。

2. 当社は、契約書に反社会的勢力排除条項を記載することを原則とする。

3. 現時点では反社チェックの実査が未整備であるため、新規取引先、重要取引先及び継続取引先から段階的に確認手続を導入する。

### 第6条（取引予定先の与信確認）

担当部門は、掛取引、後払い、継続取引、月額課金、納品前又は入金前に工数が発生する取引その他信用供与を伴う取引を行う場合、与信管理規程に従い、与信確認を行う。

2. 与信管理規程に基づき必要な承認を得た場合に限り、当該取引を開始することができる。

### 第7条（機密保持）

取引予定先又は取引先との間で、秘密情報、個人情報、ソースコード、AI関連成果物、顧客データその他重要情報を授受する場合、担当部門は、必要に応じて機密保持契約を締結する。

2. 機密保持契約又は重要な情報管理条項を含む契約を締結する場合、担当部門は、管理部又は法務担当者に内容確認を依頼する。

3. 契約書の作成、レビュー、締結及び保管は、マネーフォワード、Notion、電子契約サービスその他会社が指定する方法により行う。

## 第3章　見積及び契約

### 第8条（見積書の作成）

見積書は、原則としてマネーフォワードを使用して作成する。

2. 見積書には、提供内容、金額、税区分、支払条件、有効期限、納期又は提供期間、前提条件、成果物、検収条件その他必要な条件を明記する。

3. 担当部門は、案件ごとに売上、原価、外注費、粗利、工数、納期及びリスクを確認したうえで見積書を作成する。

4. 10万円以上の取引、通常と異なる値引き、予算外取引、重要な契約条件を含む取引その他リスクがある取引は、職務権限規程及び稟議規程に基づき、必要な承認を得る。

### 第9条（契約事項）

契約書は、原則としてマネーフォワードを使用して作成又は管理する。

2. 契約締結にあたっては、担当部門が契約内容を確認し、管理部又は法務担当者が必要に応じて契約条件、責任範囲、支払条件、知的財産、個人情報、秘密保持、反社会的勢力排除条項その他重要事項を確認する。

3. 重要な契約、10万円以上の取引、予算外取引、通常と異なる条件を含む契約その他リスクがある契約は、稟議規程に基づき事前承認を得る。

4. 契約締結権限者は、職務権限規程に従う。

### 第10条（受注）

受注は、契約書、発注書、申込書、注文書、電子的な合意記録その他受注事実を確認できる証憑に基づき確定する。

2. 担当部門は、受注内容をNotion、事業別管理資料、マネーフォワードその他会社が指定する管理資料に記録する。

3. 受注後に提供内容、金額、納期、支払条件その他重要条件を変更する場合、担当部門は、変更内容を記録し、必要な承認を得る。

## 第4章　販売管理

### 第11条（売上計上）

売上計上は、経理規程に従い、契約内容、役務提供、納品、検収、請求その他取引実態を確認したうえで行う。

2. 担当部門は、売上計上に必要な契約、受注、納品、検収、役務提供完了、請求、入金予定その他必要な情報を管理部に共有する。

3. AI研修、AI伴走、OEM、AI受託開発、SaaS、キャリアコーチングその他事業ごとの売上計上基準は、経理規程及び事業別の契約実態に基づき整理する。

### 第12条（請求書の発行）

請求書は、原則としてマネーフォワードを使用して発行する。

2. 請求書の発行にあたっては、契約内容、提供状況、検収状況、請求金額、請求先、支払期日、源泉徴収又は税区分その他必要事項を確認する。

3. 担当部門又は管理部は、請求書発行後、請求書控え、送付記録及び関連証憑を保存する。

### 第13条（代金回収）

担当部門及び管理部は、代金回収に関する責任を有する。

2. 担当部門は、受注時又は見積書提出時に支払条件を明確にし、取引先と合意した内容を契約書、申込書、発注書又は請求書に記載する。

3. 管理部は、銀行明細、請求情報、売掛金情報その他必要な資料に基づき、入金状況を確認する。

### 第14条（代金回収上の留意点）

担当部門は、代金回収のため、次の事項を遵守する。

1. 受注時又は見積書提出時に、支払条件、支払期日、請求先及び請求方法を明確にすること
2. 請求書は、契約条件及び提供状況に従い、適時に発行すること
3. 支払期日前後に入金状況を確認すること
4. 取引先との連絡を適切に行い、未入金又は支払遅延の兆候を把握すること
5. 回収懸念がある場合は、速やかに管理部及び上長に報告すること

### 第15条（債権管理）

管理部は、月次で売掛金、未収入金、入金予定及び未入金状況を確認し、必要に応じて未入金リストを作成する。

2. 担当部門は、未入金リストを確認し、未回収理由、取引先への確認状況、入金予定日及び対応方針を管理部へ報告する。

3. 重要な未入金、長期滞留債権、回収懸念又は取引条件の見直しが必要な場合、管理部は、経営会議に報告する。

4. 未入金対応及び与信判断は、与信管理規程に従う。

## 第5章　販売実績及び報告

### 第16条（販売実績管理）

担当部門は、販売実績、案件状況、営業KPI、受注見込、請求状況、入金状況及び重要な商談状況を、事業別管理資料又はNotionに記録する。

2. 管理部は、販売実績を月次決算及び予実管理に反映する。

### 第17条（報告）

担当部門は、売上見込、受注状況、請求状況、入金状況、重要な未入金、クレーム、契約上の重要論点その他販売取引に関する重要事項を経営会議に報告する。

2. 重要な売上影響、回収懸念、取引停止、重大クレーム又は法的リスクがある場合は、取締役会へ報告又は付議する。

## 第6章　保管

### 第18条（資料保管）

見積書、契約書、発注書、申込書、請求書、入金記録、取引先情報、与信確認資料、反社チェック資料、検収記録その他販売取引に関する資料は、管理部又は担当部門が保存管理する。

2. 販売取引に関する資料の保存期間は、原則として10年とする。ただし、法令又は文書管理規程によりこれより長い保存期間が定められる場合は、当該期間による。

## 第7章　改廃

### 第19条（改廃）

本規程の改廃は、規程管理規程に基づき、取締役会の決議により行う。

## 要確認事項

- 販売先の主な属性及び取引類型
- 見積書・契約書・請求書のマネーフォワード上の承認フロー
- Notionで管理している取引先情報の項目
- 売掛金・未入金管理の担当者
- 反社チェックの実施方法
- 与信確認の金額基準及び対象取引
- クレームの受付・報告ルート
- 事業別売上計上基準の詳細
