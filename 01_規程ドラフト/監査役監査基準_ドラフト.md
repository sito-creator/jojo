# 監査役監査基準（ドラフト）

会社名：株式会社MoMo

施行日：YYYY年MM月DD日

## 第1章　本基準の目的

### 第1条（目的）

本基準は、株式会社MoMo（以下「当社」という。）における監査役の職責及び行動基準を明らかにし、監査体制、監査方法、取締役会その他重要会議への関与、会計監査人等及び内部監査との連携並びに監査報告に関する基本的な指針を定めるものである。

2. 監査役は、当社の企業規模、事業内容、上場準備段階、内部管理体制の整備状況その他当社固有の監査環境に配慮し、本基準に則して監査の実効性の確保に努めなければならない。

### 第2条（監査役の職責）

監査役は、株主の負託を受けた独立の機関として、取締役の職務執行を監査し、当社の健全で持続的な成長、適正な内部管理体制及び社会的信頼の確保に寄与する責務を負う。

2. 監査役は、取締役会その他重要な会議への出席、取締役及び使用人からの報告聴取、重要文書の閲覧、業務及び財産の状況の調査、会計監査人等及び内部監査との連携等を通じて、監査意見を形成する。

## 第2章　監査役の心構え

### 第3条（独立性及び公正性）

監査役は、取締役及び業務執行部門から独立した立場を保持し、常に公正不偏の態度により監査を行わなければならない。

2. 外部監査役は、独立性、中立性及び客観性を踏まえ、代表取締役社長、取締役会及び経営会議に対して、必要な質問又は意見を述べるものとする。

### 第4条（情報収集及び自己研鑽）

監査役は、当社の事業、財務、組織、内部管理体制及び上場準備状況を理解し、適正な監査視点を形成するため、情報収集及び自己研鑽に努めなければならない。

2. 監査役は、AI研修、AI伴走、OEM、AI受託開発、SaaS、キャリアコーチングその他当社の事業特性を踏まえ、契約、情報管理、個人情報、知的財産、外注、収益認識及びシステム管理に関するリスクを把握するよう努める。

### 第5条（秘密保持）

監査役は、その職務の遂行上知り得た当社、顧客、取引先、役職員その他関係者に関する秘密情報を、正当な理由なく第三者に開示又は漏えいしてはならない。

## 第3章　監査体制

### 第6条（監査役の体制）

当社は、上場準備段階において、外部監査役1名を置くことを基本方針とする。

2. 本基準において監査役会に関する定めを置く場合であっても、監査役会を設置しない期間は、監査役が当該事項を行うものとして読み替える。

3. 監査役会を設置する場合又は監査役を複数名選任する場合には、監査役会規程、常勤監査役の選定、監査役間の職務分担及び監査役会議事録の作成保存について、別途必要な規程又は細則を整備する。

### 第7条（監査補助者）

監査役は、監査の実効性を確保するため必要がある場合、管理部、内部監査責任者、外部専門家その他監査役が適切と認める者に対し、監査資料の収集、日程調整、議事録確認その他監査業務の補助を求めることができる。

2. 監査補助者は、監査役の指示に従い、監査上知り得た情報の秘密を保持しなければならない。

### 第8条（監査費用）

監査役は、職務の執行上必要と認める費用について、会社に対して請求することができる。

2. 監査費用の支出にあたっては、監査役は、その効率性及び適正性に留意しなければならない。

## 第4章　監査環境の整備

### 第9条（代表取締役との定期的会合）

監査役は、代表取締役社長と定期的に会合を持ち、経営方針、事業上の重要課題、内部管理体制、上場準備状況、監査上の重要課題その他必要事項について意見交換を行う。

### 第10条（報告体制）

監査役は、取締役及び使用人が監査役に報告すべき事項について、代表取締役社長、取締役会及び管理部と協議し、報告体制の整備を求める。

2. 取締役及び使用人は、次の事項を発見した場合、速やかに監査役へ報告する。

1. 会社に著しい損害を及ぼすおそれのある事実
2. 法令、定款又は社内規程に違反するおそれのある事実
3. 重要な会計処理上の誤り又は財務報告上のリスク
4. 重大な情報漏えい、システム障害、個人情報事故又はクレーム
5. 反社会的勢力、関連当事者取引、外注先管理その他内部管理上の重要事項

### 第11条（内部通報制度との関係）

内部通報制度が整備されている場合、監査役は、必要に応じて通報内容、調査結果、是正措置及び再発防止策の概要について報告を受け、制度が適切に運用されているかを確認する。

## 第5章　業務監査

### 第12条（取締役の職務執行の監査）

監査役は、取締役の職務執行について、法令、定款、株主総会決議、取締役会決議及び社内規程に適合しているかを監査する。

2. 監査役は、取締役の意思決定が、十分な情報、適切な手続及び合理的な判断に基づいて行われているかを確認する。

### 第13条（内部統制システムの監査）

監査役は、取締役が内部統制システムを適切に構築し、運用しているかを監視し、検証する。

2. 監査役は、上場準備上重要な内部管理体制として、稟議、職務権限、月次決算、予実管理、販売管理、購買管理、外注管理、反社会的勢力対応、与信管理、情報セキュリティ、個人情報保護及び関連当事者取引管理の整備運用状況を確認する。

### 第14条（取締役会への出席及び意見陳述）

監査役は、取締役会に出席し、必要があると認めるときは意見を述べなければならない。

2. 監査役は、取締役会の招集、議案、資料、決議、報告及び議事録が法令、定款及び取締役会規程に従って運用されているかを確認する。

### 第15条（重要会議への出席）

監査役は、経営会議その他重要な会議に出席し、又は資料及び議事録を閲覧することにより、重要な意思決定の過程及び業務執行状況を把握する。

2. 監査役は、重要会議において必要があると認めるときは、質問又は意見を述べる。

### 第16条（重要文書の閲覧）

監査役は、取締役会議事録、経営会議議事録、稟議書、契約書、請求書、マネーフォワード上の証憑、Notion上の管理記録、月次決算資料、予実管理資料その他重要文書を閲覧し、必要に応じて取締役又は使用人に説明を求める。

### 第17条（会社財産の調査）

監査役は、現預金、売掛金、固定資産、ソフトウェア、知的財産、データ、アカウントその他重要な会社財産の取得、保有、管理及び処分の状況について調査することができる。

## 第6章　会計監査

### 第18条（会計方針及び会計処理の監査）

監査役は、当社の会計方針、会計処理、月次決算、年度決算及び財務報告が、法令、会計基準及び社内規程に照らして適切に行われているかを確認する。

2. 監査役は、会計処理上の重要な変更又は重要な見積りを伴う事項について、必要に応じて取締役、管理部又は会計監査人等から説明を受ける。

### 第19条（計算関係書類の監査）

監査役は、各事業年度の計算関係書類及び事業報告を受領し、必要に応じて取締役、管理部及び会計監査人等から説明を受け、監査報告書を作成する。

### 第20条（会計監査人等との連携）

監査役は、会計監査人、監査法人、税理士、公認会計士その他会計監査又は会計確認を担当する専門家と必要に応じて会合又は情報交換を行い、会計監査上の重要事項を確認する。

## 第7章　監査の方法

### 第21条（監査計画）

監査役は、事業年度ごとに監査方針及び監査計画を作成する。

2. 監査計画には、監査対象、監査目的、監査範囲、実施時期、監査方法、重点監査項目及び内部監査との連携方針を記載する。

3. 監査役は、監査計画を代表取締役社長及び取締役会に説明する。

### 第22条（内部監査との連携）

監査役は、内部監査責任者又は内部監査担当者と連携し、内部監査計画、内部監査結果、指摘事項及び改善状況について定期的に情報交換を行う。

2. 監査役は、内部監査の結果を監査役監査に活用し、必要に応じて内部監査責任者に追加確認又はフォローアップを求めることができる。

### 第23条（調査方法）

監査役は、資料閲覧、証憑確認、ヒアリング、業務フロー確認、サンプルテスト、会議出席、システム記録確認その他適切な方法により監査を実施する。

### 第24条（監査調書）

監査役は、監査手続、確認資料、確認結果、指摘事項、改善要請及びフォローアップ状況を監査調書として記録する。

2. 監査調書は、電子ファイル又はNotion上の記録として保存することができる。

## 第8章　監査報告

### 第25条（監査報告書）

監査役は、事業年度ごとに、監査の方法及び結果を記載した監査報告書を作成する。

2. 監査報告書には、取締役の職務執行、内部統制、会計処理、重要リスク、改善状況その他必要事項に関する監査結果を記載する。

### 第26条（取締役会への報告）

監査役は、監査報告書及び監査上重要と認める事項について、取締役会に報告する。

2. 監査役は、必要に応じて、代表取締役社長、取締役会又は経営会議に対し、助言、勧告又は改善要請を行う。

## 第9章　株主代表訴訟等への対応

### 第27条（取締役と会社間の訴え）

監査役は、当社が取締役に対し、又は取締役が当社に対して訴えを提起する場合、法令に従い当社を代表する。

### 第28条（株主代表訴訟の提訴請求）

監査役は、取締役に対する責任追及の訴えの提起を株主から請求された場合、速やかに事実関係を調査し、必要に応じて外部専門家の意見を徴したうえで、法令に従い対応する。

## 第10章　雑則

### 第29条（監査資料の保存）

監査計画、監査調書、監査報告書、会計監査人等との連携記録、内部監査との連携記録その他監査役監査に関する資料は、管理部が監査役と連携して保存管理する。

2. 監査役監査に関する資料の保存期間は、原則として10年とする。

### 第30条（改廃）

本基準の改廃は、規程管理規程に基づき、取締役会の決議により行う。

## 要確認事項

- 外部監査役候補者の氏名、属性、独立性、常勤又は非常勤の別
- 監査役会を設置する時期及び監査役会規程を別途作成するか
- 会計監査人又は監査法人との連携開始時期
- 監査役監査の年間計画、初回監査時期及び重点監査項目
- 監査役監査資料の具体的な保存場所（Notion、Google Drive等）
