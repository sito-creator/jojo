# 取締役会規程（ドラフト）

会社名：株式会社MoMo
制定日：YYYY年MM月DD日
改定日：-
主管部署：管理部
承認機関：取締役会

## 第1章 総則

### 第1条（目的）

当社の取締役会に関する事項は、法令又は定款に規定するもののほか、本規程に定めるところによる。

### 第2条（構成）

取締役会は、取締役をもって構成し、業務執行に関する重要事項を決定するとともに、取締役の職務執行を監督する。

2. 監査役は、取締役会に出席し、必要に応じて意見を述べるものとする。

### 第3条（種類及び開催）

取締役会は、定時取締役会及び臨時取締役会とする。

2. 定時取締役会は、原則として毎月1回開催する。

3. 定時取締役会は、原則として月次決算及び予実管理資料の作成後、速やかに開催する。

4. 臨時取締役会は、必要に応じて随時開催することができる。

5. 取締役会は、本社、その他議長が適当と認める場所又は電話会議、Web会議その他の電磁的方法により開催することができる。この場合、出席方法及び場所を議事録に記録する。

## 第2章 招集

### 第4条（招集権者）

取締役会は、法令に別段の定めがある場合を除き、代表取締役社長が招集する。

2. 代表取締役社長に事故があるときは、あらかじめ取締役会で定めた順序に従い、他の取締役が招集する。

### 第5条（招集手続）

招集権者は、開催日の3日前までに、各取締役及び監査役に招集通知を発するものとする。

2. 招集通知には、開催日時、開催場所又は開催方法、会議の目的事項その他必要な事項を記載又は記録する。

3. 緊急の必要がある場合は、第1項の期間を短縮することができる。

4. 取締役及び監査役全員の同意があるときは、招集手続を省略することができる。

### 第6条（招集請求）

招集権者でない取締役は、必要と認めたときは、招集権者に対し、会議の目的事項及び招集を必要とする理由を示して、取締役会の招集を請求することができる。

2. 監査役は、監査のため必要と認めたときは、招集権者に対し、取締役会の招集を請求することができる。

## 第3章 議事

### 第7条（議長）

取締役会の議長は、代表取締役社長がこれにあたる。

2. 代表取締役社長に事故があるときは、あらかじめ取締役会で定めた順序に従い、他の取締役が議長となる。

3. 会議の目的事項について議長に特別の利害関係がある場合は、当該事項について、前項に準じて他の取締役が議長となる。

### 第8条（決議事項）

取締役会に付議すべき決議事項は、法令及び定款に定める事項のほか、別表「取締役会付議基準」に定める事項とする。

### 第9条（決議方法）

取締役会の決議は、議決に加わることができる取締役の過半数が出席し、その過半数をもって行う。

2. 決議について特別の利害関係を有する取締役は、当該決議に参加することができない。

3. 前項の取締役の出席は、当該決議における定足数に算入しない。

4. 議長は、取締役会に出席できない取締役又は監査役から要請があったときは、その者の書面又は電磁的記録による意見を取締役会において伝達するものとする。

### 第10条（決議の省略）

定款に定めがある場合、取締役が取締役会の決議の目的である事項について提案したときは、当該提案につき取締役の全員が書面又は電磁的記録により同意の意思表示をし、監査役が異議を述べないときは、当該提案を可決する旨の取締役会決議があったものとみなす。

### 第11条（事後承認）

緊急その他やむを得ない事由により取締役会に付議することができないときは、代表取締役社長が必要な措置を行うことができる。

2. 前項の場合、代表取締役社長は、事後遅滞なく取締役会に報告し、その承認を受けなければならない。

### 第12条（他の者の出席）

取締役会が必要と認めたときは、取締役及び監査役以外の者を取締役会に出席させ、その説明又は意見を求めることができる。

### 第13条（監査役の意見）

議長は、監査の対象となる議案又は監査役の意見を聴取する必要がある議案については、採決に先立って監査役の意見を求めるものとする。

2. 監査役は、監査のため必要があるときは、取締役会において会議の目的事項以外の事項についても意見を述べることができる。

## 第4章 報告事項

### 第14条（報告事項）

取締役は、担当する業務の執行状況について、定期的に取締役会へ報告しなければならない。

2. 次の事項は、原則として取締役会に報告する。

1. 月次決算及び予実差異の状況
2. 資金繰り及び財務状況
3. 重要な営業活動、契約、案件の進捗
4. 重要なクレーム、事故、不祥事、法令違反又はそのおそれ
5. 内部監査及び監査役監査の結果
6. 関連当事者取引の状況
7. その他取締役会が必要と認める事項

## 第5章 議事録

### 第15条（議事録）

取締役会の議事については、法令に従い議事録を作成する。

2. 議事録には、開催日時、開催場所又は開催方法、出席者、議事の経過の要領及びその結果、決議事項、報告事項、発言の要旨その他法令で定める事項を記載又は記録する。

3. 議事録の作成担当者は、事務局が議案及び稟議内容を踏まえて定める。

4. 出席した取締役及び監査役は、議事録の内容を確認し、当面はNotion上の確認記録により確認及び承認の証跡を残す。

5. 法令、定款又は取締役会が必要と認める場合は、出席した取締役及び監査役が議事録に署名若しくは記名押印又は電子署名を行う。

### 第16条（資料の保存）

取締役会議事録、付議資料、招集通知及び確認記録は、原則としてNotionに保存する。

2. 議事録の保存期間は10年とする。ただし、文書管理規程にこれを超える保存期間の定めがある場合は、当該保存期間による。

### 第17条（欠席者に対する通知）

取締役会の議事の経過の要領及び結果は、欠席した取締役及び監査役に通知しなければならない。

## 第6章 事務局

### 第18条（事務局）

取締役会の事務局は、管理部とする。

2. 事務局は、招集通知、議案及び資料の取りまとめ、議事録の作成、資料の保存その他取締役会運営に必要な事務を行う。

## 第7章 その他

### 第19条（改廃）

本規程の改廃は、規程管理規程による。

### 第20条（その他）

取締役会の運営について、法令、定款又は本規程に定めのない事項のうち、招集に関する事項は招集権者が、その他の事項は議長が決定する。

## 別表：取締役会付議基準（たたき台）

次の事項は、取締役会の決議事項とする。

1. 経営方針、年度予算、中期経営計画その他重要な経営計画
2. 株主総会の招集、議案その他株主総会に関する事項
3. 代表取締役、役付取締役、業務執行取締役の選定及び解職
4. 取締役の担当業務、役員報酬、重要な人事に関する事項
5. 重要な組織の新設、変更及び廃止
6. 重要な規程の制定及び改廃
7. 重要な投資、出資、貸付、借入、債務保証
8. 重要な資産の取得、処分、賃貸借
9. 重要な契約の締結、変更、解除
10. 関連当事者取引、利益相反取引、競業取引
11. 重要な訴訟、紛争、事故、不祥事への対応
12. 内部監査計画及び内部監査結果の報告
13. その他法令、定款又は社内規程により取締役会決議を要する事項
