# 資金管理規程（ドラフト）

会社名：株式会社MoMo

施行日：YYYY年MM月DD日

## 第1章　総則

### 第1条（目的）

本規程は、株式会社MoMo（以下「当社」という。）の経理規程に基づき、資金管理事務に必要な事項を定め、円滑な経営活動を行うとともに、資金の調達、運用、支払、入金、資金繰り及び金融機関取引を適正かつ効率的に管理することを目的とする。

### 第2条（資金管理事務の定義）

本規程において資金管理事務とは、現金、預金、銀行口座、入金、支払、資金移動、借入、増資、資金繰り、金融機関取引その他資金の調達及び運用に関する一切の業務をいう。

### 第3条（適用範囲）

当社の資金管理に関する事項は、法令、定款、経理規程、職務権限規程、稟議規程、予算管理規程その他別に定めるもののほか、本規程による。

### 第4条（基本方針）

資金管理は、正確性、安全性、適時性、効率性及び内部牽制を重視して行う。

2. 資金の支出は、正当な取引、適切な証憑及び必要な承認に基づき行う。

3. 資金状況は、月次で把握し、経営会議及び必要に応じて取締役会へ報告する。

### 第5条（主管部署及び責任者）

資金管理の主管部署は、管理部とする。

2. 資金管理の責任者は、管理部門責任者とする。管理部門責任者が未選任又は不在の場合、代表取締役社長が資金管理責任者を指名する。

3. 資金管理責任者は、資金管理事務を統括し、資金繰り、支払、入金、銀行口座、借入及び金融機関取引の状況を把握する。

### 第6条（担当者及び承認者）

資金管理及び支払準備に関する実務は、代表取締役社長、管理部、管理部門責任者又は会社が指定する者が行う。

2. 支払、銀行振込、インターネットバンキング及び資金移動の承認は、代表取締役社長又は会社が指定する承認者が行う。

3. 10万円以上の支出は、原則として事前に稟議を行い、代表取締役社長の承認を得る。

### 第7条（牽制）

支払依頼、証憑確認、振込データ作成、支払承認及び会計処理は、可能な限り担当者を分離する。

2. 人員体制上分離が困難な場合であっても、証憑、承認履歴、振込記録、銀行明細及び会計処理記録を保存し、事後確認ができる状態を確保する。

## 第2章　資金の調達

### 第8条（資金の調達）

資金の調達は、営業収入、財務的収入その他会社が適正と認める方法により行う。

2. 営業収入とは、AI研修、AI伴走、OEM、AI受託開発、SaaS、キャリアコーチングその他当社事業に係る売上代金及びこれに準じる収入をいう。

3. 財務的収入とは、増資、借入、補助金、助成金、投資、資産売却その他営業収入以外の収入をいう。

### 第9条（金融機関との取引）

銀行その他金融機関の選択、取引開始、取引条件の変更及び取引終了は、資金管理責任者が必要性、手数料、利便性、信用力、融資可能性、内部管理上の安全性その他事情を確認し、代表取締役社長の承認を得て行う。

2. 重要な金融機関取引、借入に関連する取引、担保設定を伴う取引その他経営上重要な事項は、必要に応じて取締役会に付議する。

### 第10条（増資）

増資、新株予約権の発行その他資本政策に関する事項は、資金使途、調達金額、発行条件、株主構成、希薄化、上場準備への影響その他重要事項を整理し、法令、定款及び職務権限規程に従い、取締役会その他必要な機関の承認を得て行う。

### 第11条（借入）

借入を行う場合、資金管理責任者は、資金使途、借入金額、借入先、利率、返済条件、担保又は保証の有無、資金繰りへの影響その他必要事項を整理する。

2. 借入、返済条件の変更、借換え、担保提供、保証その他借入に関する重要事項は、職務権限規程に従い、取締役会の決議を得る。

### 第12条（補助金及び助成金）

補助金、助成金その他公的支援金の申請、受領及び管理を行う場合、担当部門は、申請要件、対象経費、入金予定、返還リスク、収益又は費用への影響を管理部へ報告する。

2. 管理部は、補助金及び助成金の入金、対象経費、会計処理及び証憑保存を確認する。

### 第13条（担保の提供及び保証）

会社財産を金融機関その他第三者に担保として提供する場合又は債務保証を行う場合は、取締役会の承認を得なければならない。

2. 担保提供又は保証は、事業上及び資金管理上やむを得ない場合に限り行う。

## 第3章　資金の運用

### 第14条（資金の運用）

資金の運用は、営業支出、財務的支出その他会社が適正と認める支出により行う。

2. 営業支出とは、通常の営業活動、事業運営、人件費、外注費、購買、経費、販売管理費その他営業活動に伴う支出をいう。

3. 財務的支出とは、借入金返済、投資、出資、貸付、固定資産取得、保証、資金移動その他営業外又は財務活動に伴う支出をいう。

### 第15条（預金の管理）

銀行その他金融機関に対する預金は、資金計画、入出金予定、安全性、手数料、利便性及び資金効率を考慮して管理する。

2. 管理部は、銀行名、支店名、口座種別、口座番号、用途、管理者、利用権限者を記録した銀行口座一覧を管理する。

### 第16条（銀行口座の開設、変更及び解約）

銀行口座の開設、変更及び解約は、代表取締役社長の承認を得て行う。

2. 銀行口座は、事業上又は管理上必要な範囲で保有し、利用実態のない口座は適宜見直す。

### 第17条（インターネットバンキング権限）

インターネットバンキングの利用者、承認者及び権限範囲は、管理部が一覧管理する。

2. インターネットバンキングの承認権限者は、代表取締役社長又は会社が指定する者とする。

3. 利用者の追加、削除、権限変更及び認証情報の管理は、代表取締役社長の承認を得て行う。

4. 退職、異動、担当変更その他権限変更が必要となった場合、管理部は速やかに権限の削除又は変更を行う。

### 第18条（投資及び貸付）

投資、出資、貸付その他資金を長期又は重要な目的で運用する場合は、資金使途、金額、回収可能性、リスク、資金繰りへの影響及び会計処理を整理し、職務権限規程及び稟議規程に従い、必要な承認を得る。

2. 重要な投資、出資又は貸付は、取締役会の承認を得る。

### 第19条（資金移動）

当社名義の銀行口座間で資金移動を行う場合、移動目的、金額、移動元口座、移動先口座及び実行日を明確にし、代表取締役社長又は会社が指定する承認者の承認を得る。

2. 資金移動記録及び銀行明細は、管理部が保存管理する。

## 第4章　支払及び入金管理

### 第20条（支払の原則）

支払は、銀行振込、口座振替、クレジットカード、現金その他会社が認める方法により行う。

2. 支払は、請求書、契約書、発注内容、検収状況、納品状況、稟議記録その他必要な証憑を確認したうえで行う。

3. 手形による支払は、原則として行わない。手形取引を行う必要が生じた場合は、取締役会の承認を得る。

### 第21条（支払手続）

支払依頼者は、支払先、支払金額、支払期日、支払内容、関連する稟議番号又は契約情報を明確にし、会社が指定する方法により申請する。

2. 支払担当者は、証憑、承認履歴、支払先口座、金額、支払期日及び会計処理との整合性を確認する。

### 第22条（支払承認及び振込）

支払及び銀行振込は、代表取締役社長又は会社が指定する承認者の承認を得て実行する。

2. 振込データ又は振込内容を作成した者は、支払先、金額、口座情報、支払期日及び証憑との整合性を確認する。

3. 振込実行後、振込記録及び銀行明細を保存する。

### 第23条（経費精算）

経費精算は、原則としてマネーフォワードにより申請、承認及び証憑保存を行う。

2. 経費精算であっても、10万円以上の支出、予算外支出又は重要な支出については、事前稟議を要する。

### 第24条（入金確認）

管理部は、銀行明細、請求情報、売掛金管理資料、マネーフォワードその他必要な資料に基づき、入金状況を確認する。

2. 入金内容が不明な場合又は請求情報と一致しない場合、管理部は担当部門と連携して原因を確認する。

### 第25条（未入金管理）

入金予定日を経過しても入金が確認できない場合、管理部は、担当部門と連携して状況を確認し、必要な督促、請求内容の確認、支払予定日の確認その他回収対応を行う。

2. 重要な未入金、長期滞留債権又は回収懸念がある場合は、経営会議に報告する。

## 第5章　資金予算及び資金繰り

### 第26条（資金予算の区分）

資金予算は、次の区分により管理する。

1. 中期経営計画又はこれに準じる経営方針に基づく資金計画
2. 年度予算に基づく年間資金計画
3. 月次予算に基づく月次資金繰り
4. 必要に応じて作成する短期資金繰り

### 第27条（資金繰り管理）

管理部は、資金残高、入金予定、支払予定、借入返済予定、税金支払予定、人件費支払予定、投資予定その他資金繰りに必要な情報を管理する。

2. 資金繰りの状況は、月次決算及び予実管理とあわせて経営会議に報告する。

3. 資金繰りに重大な影響を与える事項がある場合は、速やかに代表取締役社長へ報告し、必要に応じて取締役会に報告又は付議する。

### 第28条（資金繰り予実管理）

管理部は、資金繰りの予算又は見込と実績を比較し、重要な差異がある場合は、その内容、原因及び対応方針を整理する。

2. 資金繰り予実の差異分析は、予算管理規程に基づく月次予実管理と連動して行う。

## 第6章　現金及び仮払

### 第29条（現金管理）

現金を保有する場合、管理部は、保管場所、管理者、残高、入出金履歴を管理する。

2. 現金の保有は必要最小限とする。

3. 現金残高は、定期的に帳簿残高と実際残高を照合する。

### 第30条（仮払）

仮払を行う場合、目的、金額、精算予定日及び承認者を明確にする。

2. 仮払を受けた者は、用務完了後速やかに精算しなければならない。

3. 長期未精算の仮払がある場合、管理部は、対象者及び承認者へ確認し、速やかに精算又は返金を求める。

## 第7章　報告書類及び調査事項

### 第31条（報告書類）

資金に関する報告書類は、次のとおりとする。

1. 資金繰り表
2. 資金繰り予実比較表
3. 資金残高一覧表
4. 支払予定表
5. 入金予定表
6. 借入金残高表
7. 銀行別取引状況一覧表
8. 未入金一覧表
9. 投資、貸付及び保証に関する明細表
10. その他資金管理責任者が必要と認める資料

### 第32条（調査事項）

資金管理責任者又は管理部は、資金の調達及び運用に関する資料とするため、次の事項について適時調査又は確認を行う。

1. 経済情勢及び金融動向
2. 取引金融機関の取引条件及び融資姿勢
3. 売上代金の回収状況
4. 主要取引先の信用状態
5. 重要な支払予定
6. 借入、増資、補助金その他資金調達手段
7. 資金繰りに影響する重要な事業計画又は投資計画

### 第33条（保存）

支払証憑、振込記録、銀行明細、入金記録、資金繰り資料、借入契約書、金融機関取引資料その他資金管理に関する資料は、管理部が保存管理する。

2. 資金管理に関する資料の保存期間は、原則として10年とする。ただし、法令又は文書管理規程によりこれより長い保存期間が定められる場合は、当該期間による。

## 第8章　改廃

### 第34条（改廃）

本規程の改廃は、規程管理規程に基づき、取締役会の決議により行う。
