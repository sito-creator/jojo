# 資金管理規程（ドラフト）

制定日：YYYY年MM月DD日

承認機関：取締役会

## 第1章 総則

### 第1条（目的）

本規程は、株式会社MoMoにおける資金の管理、支払、入金、銀行口座、インターネットバンキング、資金繰り及び借入に関する基本事項を定め、資金管理の適正性と安全性を確保することを目的とする。

### 第2条（適用範囲）

会社の現金、預金、銀行口座、支払、入金、資金移動、借入、資金繰りその他資金に関する事項は、法令、定款その他別に定めるもののほか、本規程による。

### 第3条（基本方針）

資金管理は、正確性、安全性、適時性及び牽制を重視して行う。

2. 資金の支出は、正当な取引、適切な証憑及び必要な承認に基づき行う。

3. 資金の状況は、月次で把握し、経営会議及び必要に応じて取締役会へ報告する。

## 第2章 管理体制

### 第4条（主管部署）

資金管理の主管部署は、管理部とする。

### 第5条（担当者）

資金管理及び支払準備に関する実務は、伊藤翔及び柿塚が担当する。

### 第6条（承認者）

支払、銀行振込、インターネットバンキング及び資金移動の承認は、伊藤翔が行う。

2. 10万円以上の支出は、原則として事前に稟議を行い、伊藤翔の承認を得る。

### 第7条（牽制）

支払依頼、証憑確認、振込データ作成、支払承認及び会計処理は、可能な限り担当者を分離する。

2. 人員体制上分離が困難な場合であっても、証憑、承認履歴、振込記録及び会計処理記録を保存し、事後確認ができる状態にする。

## 第3章 銀行口座及びインターネットバンキング

### 第8条（銀行口座の開設及び解約）

銀行口座の開設、変更及び解約は、代表取締役社長の承認を得て行う。

2. 重要な銀行口座の開設、借入に関連する口座設定その他経営上重要な事項は、必要に応じて取締役会に付議する。

### 第9条（銀行口座の管理）

管理部は、銀行名、支店名、口座種別、口座番号、用途、管理者、利用権限者を記録した銀行口座一覧を管理する。

### 第10条（インターネットバンキング権限）

インターネットバンキングの利用者、承認者及び権限範囲は、管理部が一覧管理する。

2. インターネットバンキングの承認権限者は、伊藤翔とする。

3. 利用者の追加、削除、権限変更は、伊藤翔の承認を得て行う。

## 第4章 支払管理

### 第11条（支払手続）

支払は、請求書、契約書、発注内容、検収状況、納品状況その他必要な証憑を確認したうえで行う。

2. 支払依頼者は、支払先、支払金額、支払期日、支払内容、関連する稟議番号又は契約情報を明確にする。

### 第12条（支払承認）

支払は、伊藤翔の承認を得て実行する。

2. 10万円以上の支払、予算外支出、通常と異なる支払条件、前払金、仮払金その他重要な支払は、事前稟議を要する。

### 第13条（振込）

銀行振込を行う場合、振込データ又は振込内容を作成した者は、支払先、金額、口座情報、支払期日及び証憑との整合性を確認する。

2. 振込実行前に、伊藤翔の承認を得る。

3. 振込実行後、振込記録及び銀行明細を保存する。

### 第14条（経費精算）

経費精算は、原則としてマネーフォワードにより申請、承認及び証憑保存を行う。

2. 経費精算の承認者は、伊藤翔とする。

## 第5章 入金管理

### 第15条（入金確認）

管理部は、銀行明細、請求情報、売掛金管理資料その他必要な資料に基づき、入金状況を確認する。

### 第16条（未入金管理）

入金予定日を経過しても入金が確認できない場合、管理部は、担当部門と連携して状況を確認し、必要な対応を行う。

2. 重要な未入金又は回収懸念がある場合は、経営会議に報告する。

## 第6章 資金繰り及び借入

### 第17条（資金繰り管理）

管理部は、資金残高、入金予定、支払予定、借入返済予定その他資金繰りに必要な情報を管理する。

2. 資金繰りの状況は、月次決算及び予実管理とあわせて経営会議に報告する。

### 第18条（借入及び資金調達）

借入、返済条件の変更、担保提供、保証その他資金調達に関する重要事項は、取締役会の決議を得る。

2. 借入又は資金調達を検討する場合、管理部は、資金使途、金額、条件、返済計画、資金繰りへの影響を整理する。

## 第7章 現金及び仮払

### 第19条（現金管理）

現金を保有する場合、管理部は、保管場所、管理者、残高、入出金履歴を管理する。

2. 現金の保有は必要最小限とする。

### 第20条（仮払）

仮払を行う場合、目的、金額、精算予定日及び承認者を明確にする。

2. 仮払を受けた者は、用務完了後速やかに精算しなければならない。

## 第8章 保存及び報告

### 第21条（資料保存）

支払証憑、振込記録、銀行明細、入金記録、資金繰り資料、借入契約書その他資金管理に関する資料は、管理部が保存管理する。

### 第22条（報告）

管理部は、月次で資金残高、資金繰り、重要な支払、未入金、借入状況を経営会議に報告する。

2. 資金繰りに重大な影響を与える事項がある場合は、取締役会に報告又は付議する。

## 第9章 改廃

### 第23条（改廃）

本規程の制定、改廃は、取締役会の決議による。

## 附則

## 要確認事項

- 銀行口座の一覧
- インターネットバンキングの利用者一覧
- 振込データ作成者
- 支払予定表の有無
- 資金繰り表の有無
- 売掛金・入金管理の方法
- 現金、仮払金の運用有無
- 借入の有無及び金融機関との取引状況

- 支払、銀行振込、インターネットバンキング承認は伊藤翔が行う。
- 経理実務は伊藤翔及び柿塚が担当する。
- 10万円以上の支出は伊藤翔の事前承認とする。
- 経費精算はマネーフォワードを使用している。
