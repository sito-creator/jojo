# 賃金規程（ドラフト）

会社名：株式会社MoMo

施行日：YYYY年MM月DD日

## 第1章　総則

### 第1条（目的）

本規程は、株式会社MoMo（以下「当社」という。）の従業員の賃金に関する基本事項を定める。

2. 本規程は、就業規則、雇用契約書、労働条件通知書その他社労士レビュー済みの既存労務規程と整合するよう運用し、差異がある場合は、社労士確認のうえ必要な改定を行う。

### 第2条（適用範囲）

本規程は、就業規則に定める社員に適用する。

2. パートタイマー、契約社員その他就業形態又は契約形態が異なる者について、個別契約、就業規則又は別に定める規程に本規程と異なる定めがある場合は、当該定めを優先する。

### 第3条（賃金の構成）

賃金の構成は、原則として次のとおりとする。

1. 基本給
2. 固定残業手当
3. 通勤手当
4. 時間外勤務手当、休日勤務手当及び深夜勤務手当
5. その他会社が必要と認める手当
6. 賞与

2. 会社は、職務内容、役割、雇用契約又は労働条件通知書により、年俸制その他個別の賃金形態を定めることができる。

### 第4条（賃金の決定）

基本給その他賃金は、職務内容、役割、責任、能力、経験、勤務成績、会社業績、採用条件及び市場水準等を総合的に勘案し、各人ごとに決定する。

2. 賃金の新設、変更、昇給、降給その他処遇変更は、人事評価規程、職務権限規程及び稟議規程に従い、必要な承認を得て行う。

## 第2章　賃金の計算及び支払

### 第5条（計算期間及び支払日）

賃金は、毎月1日から末日までを計算期間とし、翌月20日に支給する。

2. 前項の支払日が金融機関休業日にあたるときは、前営業日に繰り上げて支給する。

### 第6条（支払方法及び控除）

賃金は、通貨又は従業員の同意を得たうえで本人名義の銀行口座への振込により、直接、全額を支払う。

2. 前項にかかわらず、次の各号に掲げるものは、賃金支払時に控除する。

1. 所得税
2. 住民税
3. 雇用保険料
4. 健康保険料
5. 介護保険料
6. 厚生年金保険料
7. 法令又は労使協定に基づき控除するもの

### 第7条（日割計算）

賃金計算期間の途中で入社、退職、休職、復職又は賃金変更があった場合、賃金は会社が別に定める方法により日割計算する。

2. 日割計算の方法は、原則として次の式による。

月額賃金 ÷ 当該賃金計算期間の暦日数 × 在籍暦日数

3. 会社は、就業規則、雇用契約、労働条件通知書又は既存労務規程に別段の定めがある場合、当該定めに従う。

### 第8条（欠勤、遅刻、早退等）

欠勤、遅刻、早退、私用外出その他所定労働時間の全部又は一部について労務提供がなかった場合、会社は、その不就労時間に対応する賃金を支給しないことができる。

2. 不就労控除の計算方法は、就業規則、雇用契約、労働条件通知書又は既存労務規程に従う。

### 第9条（端数処理）

賃金計算において生じる円未満の端数は、法令又は会社が別に定める方法に従い処理する。

2. 時間外勤務手当、休日勤務手当、深夜勤務手当その他割増賃金の計算における端数処理は、労働基準法その他関係法令に従う。

### 第10条（休職者の賃金）

休職期間中の賃金は、就業規則、雇用契約、労働条件通知書又は会社が別に定める規程に従う。

### 第11条（休暇等の賃金）

年次有給休暇その他有給と定められた休暇については、就業規則又は法令に従い通常の賃金を支給する。

2. 無給と定められた休暇、休業又は不就労期間については、賃金を支給しない。

### 第12条（休業手当）

会社の責めに帰すべき事由により社員を休業させた場合は、労働基準法第26条に定める平均賃金の100分の60以上の休業手当を支払う。

## 第3章　割増賃金及び固定残業手当

### 第13条（時間外勤務手当）

会社が時間外勤務を命じた場合、会社は、労働基準法その他関係法令に従い、時間外勤務手当を支給する。

2. 時間外勤務手当は、原則として次の式により算出する。

割増賃金の基礎となる賃金 ÷ 1か月平均所定労働時間 × 法定割増率 × 時間外勤務時間数

### 第14条（休日勤務手当）

会社が休日勤務を命じた場合、会社は、労働基準法その他関係法令に従い、休日勤務手当を支給する。

### 第15条（深夜勤務手当）

深夜時間帯に勤務した場合、会社は、労働基準法その他関係法令に従い、深夜勤務手当を支給する。

### 第16条（固定残業手当）

会社は、雇用契約書又は労働条件通知書に明示した場合、月10時間分の時間外勤務に相当する固定残業手当を支給することができる。

2. 固定残業手当を支給する場合、基本給と固定残業手当を明確に区分し、固定残業手当の金額及びこれに対応する時間数を雇用契約書又は労働条件通知書に明示する。

3. 実際の時間外勤務、休日勤務又は深夜勤務に対する割増賃金が固定残業手当の額を超える場合、会社は、その超過額を追加で支給する。

4. 固定残業手当は、時間外勤務を命じることを当然に予定又は保証するものではない。

### 第17条（適用除外）

労働基準法第41条その他関係法令により割増賃金の適用除外となる者については、法令及び個別契約に従い取り扱う。

## 第4章　基本給及び賃金改定

### 第18条（基本給の決定）

基本給は、従業員の職務内容、役割、責任、能力、経験、勤務成績、会社業績及び市場水準等を総合的に勘案し、各人ごとに決定する。

### 第19条（賃金改定）

賃金改定は、会社が必要と認めた場合に行う。

2. 基本給及び諸手当等の昇給は、会社の業績、勤務成績その他を踏まえ、原則として毎年4月1日に行うものとする。

3. 会社は、組織変更、職務変更、昇格、降格、雇用条件変更、業績状況その他必要がある場合、前項にかかわらず賃金を改定することができる。

4. 賃金改定を行う場合、会社は、雇用契約書、労働条件通知書その他必要な書面又は電子的方法により、従業員に通知する。

## 第5章　諸手当

### 第20条（通勤手当）

会社は、従業員が公共交通機関を利用して通勤する場合、合理的かつ経済的な経路に基づき、通勤手当を支給することができる。

2. 通勤手当の支給方法、上限額、変更手続その他詳細は、会社が別に定める。

### 第21条（その他手当）

会社は、業務上必要がある場合、役職手当、職務手当、在宅勤務手当、資格手当その他臨時又は暫定的な手当を支給することができる。

2. その他手当の支給対象、金額、支給期間及び廃止については、会社が個別に定める。

## 第6章　賞与

### 第22条（賞与の支給）

会社は、会社業績、部門業績、個人の勤務成績、貢献度、勤務態度その他会社が必要と認める事項を総合的に勘案し、通常賞与を支給することがある。

2. 賞与は、支給を保証するものではなく、会社の業績、資金状況その他やむを得ない事情により、支給しないこと又は支給額を変更することがある。

### 第23条（賞与の支給時期）

賞与は、原則として年3回、5月、9月及び1月の会社が定める日に支給する。

2. 会社は、会社の業績、資金状況その他やむを得ない事情により、賞与の支給時期を延期し、又は支給しないことがある。

### 第24条（賞与の算定対象期間）

賞与の算定対象期間は、原則として次のとおりとする。

| 賞与支給月 | 算定対象期間 |
| --- | --- |
| 5月 | 当年1月1日から当年4月30日まで |
| 9月 | 当年5月1日から当年8月31日まで |
| 1月 | 前年9月1日から前年12月31日まで |

### 第25条（賞与の算定基準）

賞与の算定基準は、算定対象期間における会社業績、部門業績、個人の評価結果、出勤状況、貢献度、役割及び職務内容を総合的に勘案して、各人ごとに決定する。

### 第26条（賞与の支給条件）

賞与は、原則として支給日に在籍している従業員を対象として支給する。

2. 算定対象期間の途中で入社、休職、復職、退職予定その他通常と異なる事情がある者については、会社が個別に支給の有無及び支給額を決定する。

## 第7章　雑則

### 第27条（賃金台帳及び保存）

会社は、法令に従い賃金台帳を作成し、賃金計算、支給、控除及び勤怠に関する資料を保存する。

2. 賃金台帳及び賃金に関する資料の保存期間は、法令に従う。ただし、上場準備、労務紛争対応、税務調査、監査対応その他会社が必要と認める場合は、必要な期間保存することができる。

### 第28条（個別契約との関係）

雇用契約書又は労働条件通知書に本規程と異なる定めがある場合であっても、法令に反する取扱いは行わない。

2. 個別契約により職務、役割、賃金形態又は手当を定める場合、会社は、本規程、就業規則及び関係法令との整合を確認する。

### 第29条（改廃）

本規程の改廃は、規程管理規程に基づき、取締役会の決議により行う。

## 要確認事項

- 既存の社労士レビュー済み就業規則・賃金規程との条文整合
- 就業規則第39条の「毎月20日に支払う」という記載を、会社実態に合わせて「翌月20日」に修正するか
- 就業規則第19条の始業9時、終業19時、休憩60分と、1日8時間の記載整合
- 固定残業手当10時間分の具体的な金額、計算方法、労働条件通知書の記載内容
- 1か月平均所定労働時間、所定休日、法定休日、深夜勤務の管理方法
- 通勤手当、在宅勤務手当、役職手当その他手当の有無及び上限額
- 就業規則第41条の賞与算定対象期間に「4月31日」「8月30日」と記載があるため、4月30日、8月31日へ修正するか
- 賃金台帳、勤怠、給与計算資料の保存場所及び保存期間
