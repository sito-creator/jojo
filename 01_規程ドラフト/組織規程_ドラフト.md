## 第1章 総則

### 第1条（目的）

本規程は、株式会社MoMoにおける組織の基本構造、職制及び各組織の役割を定め、業務の効率的な遂行と責任体制の明確化を図ることを目的とする。

### 第2条（適用範囲）

会社の組織及び職制に関する事項は、法令、定款その他別に定めるもののほか、本規程による。

### 第3条（組織運営の基本方針）

会社は、業務執行の責任と権限を明確にし、管理部門と事業部門の牽制が機能する組織運営を行う。

2. 組織の新設、変更及び廃止は、取締役会の決議又は代表取締役社長の承認により行う。

## 第2章 会議体

### 第4条（取締役会）

取締役会は、法令、定款及び取締役会規程に基づき、経営上の重要事項を決定し、取締役の職務執行を監督する。

### 第5条（経営会議）

経営会議は、業務執行上の重要事項を審議、協議及び報告する会議体として設置する。

2. 経営会議の運営は、経営会議規程に定める。

## 第3章 組織

### 第6条（本部及び部門）

会社に、次の本部及び部門を置く。

1. 管理本部
2. 営業部
3. 研修事業部
4. 開発部
5. 新規事業部

### 第7条（管理本部）

管理本部は、総務、人事、広報、法務その他管理業務を所管する。

2. 管理本部の責任者は、出水とする。

3. 管理本部に、次の部門を置く。

1. 総務
2. 人事
3. 広報部
4. 法務部

### 第8条（営業部）

営業部は、営業活動、顧客対応、見積、受注、販売管理その他営業に関する業務を所管する。

2. 営業部の責任者は、安東とする。

### 第9条（研修事業部）

研修事業部は、生成AI研修その他研修サービスの企画、運営、提供及び品質管理を所管する。

2. 研修事業部の責任者は、有賀とする。

### 第10条（開発部）

開発部は、システム、AIサービス、プロダクトその他開発業務を所管する。

2. 開発部の責任者は、菅とする。

### 第11条（新規事業部）

新規事業部は、新規事業、プロダクト、サービスの企画、立上げ、推進及び管理を所管する。

2. 新規事業部の責任者は、柿塚とする。

3. 新規事業部に、次の事業を置く。

1. 補助金事業
2. ロムちゃん（ローカルLLM）
3. すぐつくAI
4. Context Chat

## 第4章 職制

### 第12条（職制）

会社の職制は、代表取締役、取締役、本部長、部長、担当者その他会社が必要と認める職位とする。

### 第13条（兼務）

業務上必要がある場合、役員又は従業員は複数の組織又は職務を兼務することができる。

2. 兼務を行う場合であっても、営業、管理、経理、承認及び監査に関する牽制が損なわれないよう留意する。

## 第5章 改廃

### 第14条（改廃）

本規程の制定、改廃は、取締役会の決議による。
