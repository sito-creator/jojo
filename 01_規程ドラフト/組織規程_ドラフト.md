## 第1章 総則

### 第1条（目的）

本規程は、株式会社MoMoの経営組織の基本を定め、職務の責任と権限、命令系統を明らかにし、業務の確実かつ効率的な執行と運用を図ることを目的とする。

## 第2章 組織及び業務分掌

### 第2条（組織単位）

会社は、業務上必要に応じて、次の組織単位を置くことができる。

1. 本部
2. 部
3. 事業部
4. 室
5. チームその他会社が必要と認める単位

### 第3条（組織図）

会社の組織は、別紙組織図のとおりとする。

2. 会社は、現時点において、次の本部及び部門を置く。

1. 管理本部
2. 営業部
3. 研修事業部
4. 開発部
5. 新規事業部

3. 組織の新設、変更及び廃止は、取締役会の決議又は代表取締役社長の承認により行う。

### 第4条（業務分掌）

各組織単位の分掌業務は、別に定める業務分掌規程による。

### 第5条（会議体）

取締役会は、法令、定款及び取締役会規程に基づき、経営上の重要事項を決定し、取締役の職務執行を監督する。

2. 経営会議は、業務執行上の重要事項を審議、協議及び報告する会議体として設置する。

3. 経営会議の運営は、経営会議規程に定める。

## 第3章 職位及び権限

### 第6条（代表取締役社長の職務）

代表取締役社長は、会社を代表し、法令、定款、株主総会及び取締役会の決定に基づき、会社業務を総括する。

### 第7条（取締役の職務）

取締役は、取締役会の構成員として会社全般にわたる業務活動の管理に参画し、代表取締役社長の委任する担当業務を行う。

### 第8条（職位）

会社は、組織に基づき、必要に応じて次の職位を置くことができる。

1. 本部長
2. 部長
3. 事業部長
4. 室長
5. チーム責任者
6. 担当者
7. その他会社が必要と認める職位

2. 前項に定めのない職位であっても、業務上必要がある場合は、代表取締役社長の承認により置くことができる。

### 第9条（職務及び権限）

各職位者は、それぞれ所属長の命令及び監督を受けて所管業務を遂行し、その責任を負う。

2. 職務の遂行に必要な職務権限は、別に定める職務権限規程及び決裁権限基準表による。

### 第10条（兼務）

業務上必要がある場合、役員又は従業員は複数の組織又は職務を兼務することができる。

2. 兼務を行う場合であっても、営業、管理、経理、承認及び監査に関する牽制が損なわれないよう留意する。

### 第10条の2（業務委託者の位置付け）

会社は、業務上必要がある場合、業務委託者に対し、実務担当、実務支援その他必要な業務を委託することができる。

2. 業務委託者は、個別契約、業務委託契約、発注条件その他会社との契約に基づき業務を遂行する。

3. 業務委託者が担当又は支援する業務であっても、会社の業務執行、承認、決裁及び内部管理上の最終責任は、会社の役員、従業員又は会社が定める社内責任者が負う。

## 第4章 現行組織

### 第11条（管理本部）

管理本部は、総務、人事、広報、法務その他管理業務を所管する。

2. 管理本部の責任者は、出水とする。

3. 管理本部に、次の部門を置く。

1. 総務
2. 人事
3. 広報部
4. 法務部

### 第12条（営業部）

営業部は、営業活動、顧客対応、見積、受注、販売管理その他営業に関する業務を所管する。

2. 営業部の責任者は、土屋とする。

### 第13条（研修事業部）

研修事業部は、生成AI研修その他研修サービスの企画、運営、提供及び品質管理を所管する。

2. 研修事業部の責任者は、有賀とする。

### 第14条（開発部）

開発部は、システム、AIサービス、プロダクトその他開発業務を所管する。

2. 開発部の実務担当は、菅（業務委託）とする。

3. 開発部の社内管掌責任者は、代表取締役社長又は取締役会が別途定める者とする。

4. 開発部に、SaaS事業部を置く。

5. SaaS事業部は、SaaSサービスの企画、開発、運用、保守、改善、障害対応及び利用者管理に関する業務を所管する。

### 第15条（新規事業部）

新規事業部は、新規事業、プロダクト、サービスの企画、立上げ、推進及び管理を所管する。

2. 新規事業部の責任者は、柿塚とする。

3. 新規事業部に、次の事業を置く。

1. 補助金事業
2. キャリアコーチング事業
