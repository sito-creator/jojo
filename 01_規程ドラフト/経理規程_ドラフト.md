# 経理規程（ドラフト）

会社名：株式会社MoMo

施行日：YYYY年MM月DD日

## 第1章　総則

### 第1条（目的）

本規程は、株式会社MoMo（以下「当社」という。）の経理に関する基準を定め、会計に関する取引を正確かつ迅速に処理し、当社の財政状態及び経営成績について真実かつ明瞭な報告を行うとともに、経営活動の計数的統制及び効率的な運営に資する資料を提供することを目的とする。

### 第2条（適用範囲）

当社の経理処理、決算、税務申告、会計帳簿及び証憑の保存に関する事項は、法令、会計基準、税務関係法令、定款、職務権限規程、稟議規程、資金管理規程その他別に定めるもののほか、本規程による。

2. 本規程に定めのない事項又は本規程によりがたい重要事項については、一般に公正妥当と認められる企業会計の基準及び経理責任者の指示に従う。

### 第3条（内部統制）

会計記録の正確性及び信頼性を確保し、経理に関する不正、誤謬、漏れ、重複処理その他不適切な処理を防止するため、当社は、申請、承認、支払準備、支払承認、会計入力及び確認の職務を可能な限り分離する。

2. 人員体制上、職務分離が困難な場合であっても、証憑、承認履歴、処理履歴及び確認記録を保存し、事後検証が可能な状態を確保する。

### 第4条（経理責任者）

経理処理に関する責任者は、取締役の柿塚とする。

2. 経理責任者が不在又は職務を遂行できない場合、代表取締役社長が代替の経理責任者又は確認者を指名する。

### 第5条（会計年度）

当社の会計年度は、定款の定める事業年度に従い、毎年7月1日から翌年6月30日までとする。

### 第6条（会計単位）

当社の会計処理は、本社で集中して管理する。

2. 各部門は、日々発生する会計取引について、取引の発生部署として必要な申請、証憑提出、検収確認、実績報告その他会計処理に必要な情報提供を行う。

3. 会計処理、経費精算、請求管理及び給与計算は、原則としてマネーフォワードその他会社が指定するシステムを利用して行う。

### 第7条（経理業務の範囲）

経理業務の範囲は、業務分掌規程に定めるほか、次の事項を含む。

1. 会計帳簿及び仕訳の作成、確認及び管理
2. 売上、原価、経費、未収入金、売掛金、未払金、買掛金その他会計処理
3. 経費精算、支払準備、振込データ確認及び支払記録の管理
4. 月次決算、四半期決算及び年度決算
5. 予実管理資料及び事業別実績資料との照合
6. 税務申告、税務調査及び外部専門家対応
7. 会計帳簿、証憑及び決算資料の保存管理

### 第8条（経理担当者）

経理実務は、代表取締役社長である伊藤翔及び取締役の柿塚が行う。

2. 経理担当者は、日常の会計処理、証憑確認、支払準備、月次決算資料の作成、事業別実績の確認その他経理に必要な業務を行う。

## 第2章　会計手続

### 第9条（正規の簿記の原則）

当社におけるすべての会計取引は、その発生を証する証憑に基づき、会計帳簿に秩序をもって整理、集計及び記録しなければならない。

### 第10条（証憑）

証憑とは、当社の内部又は外部で発行される資料で、取引の裏付けとなるものをいう。

2. 証憑には、契約書、注文書、発注書、請求書、領収書、納品書、検収記録、入金記録、銀行明細、マネーフォワード上の申請及び承認記録、Notion上の稟議記録その他取引内容を確認できる資料を含む。

3. 取引の担当部門は、当該証憑が正当なものであることを確認し、管理部に提出又は共有しなければならない。

### 第11条（勘定科目）

当社の勘定科目及びその整理要領は、会社が採用する会計システム、税理士又は会計事務所の助言及び経理責任者の指示に従う。

2. 勘定科目の新設、改廃又は重要な運用変更は、経理責任者の承認を得なければならない。

### 第12条（仕訳及び会計入力）

経理担当者は、勘定科目及び会計方針に従い、会計上の取引を発生の都度又は月次決算手続において、証憑に基づき仕訳又は会計入力する。

2. 仕訳及び会計入力は、経理担当者が確認し、経理責任者又は会社が指定する確認者が必要に応じて処理内容を確認する。

### 第13条（会計帳簿等の保存）

会計帳簿、仕訳、証憑、決算資料、税務申告資料その他経理関係資料は、管理部が保存管理する。

2. 保存期間は、法令、文書管理規程又は本規程に定める期間のいずれか長い期間とする。

3. 保存期間を経過した資料を廃棄する場合は、経理責任者の承認を得なければならない。

### 第14条（機密保持）

経理業務に関与する者は、当社の財務情報、取引情報、顧客情報、役職員情報その他職務上知り得た秘密を、正当な理由なく第三者に開示又は漏えいしてはならない。

2. 決算数値その他重要な経理情報を社外へ公表又は提供する場合は、法令、取引所規則、情報開示規程その他社内規程に従い、必要な承認を得る。

## 第3章　会計方針及び重要取引

### 第15条（重要な会計方針）

当社の重要な会計方針は、一般に公正妥当と認められる企業会計の基準、税務関係法令及び会社が採用する会計方針に従う。

2. 本規程に定めのない会計方針、会計上の見積り又は重要な判断を要する事項は、経理責任者が税理士、監査法人その他外部専門家と協議のうえ定める。

### 第16条（収益及び費用の計上基準）

売上は、契約内容、役務提供、納品、検収、請求その他取引実態を確認したうえで、適切な会計期間に計上する。

2. 事業ごとの売上計上基準の初期案は、次のとおりとする。ただし、契約内容、サービス提供形態、会計基準及び税理士法人cosmosその他外部専門家の助言に基づき、必要に応じて見直す。

| 事業又は取引類型 | 売上計上基準の初期案 |
| --- | --- |
| AI研修 | 役務提供完了時 |
| AI伴走 | 役務提供完了時 |
| AI受託開発 | 検収時 |
| OEM | 検収時 |
| SaaS | 利用期間に応じて月次 |
| 補助金事業 | 収益認識条件の確定時 |
| その他 | 契約内容及び取引実態に応じて管理部が確認 |

3. 費用は、発生事実及び証憑を確認したうえで、適切な会計期間に計上する。

### 第17条（経費精算）

経費精算は、原則としてマネーフォワードにより申請、承認及び証憑保存を行う。

2. 経費精算であっても、10万円以上の支出、予算外支出、重要な支出又は職務権限規程及び稟議規程に定める事項については、事前稟議又は必要な承認を得なければならない。

### 第18条（借財及び担保提供）

借入、債務保証、担保提供その他借財に関する事項は、職務権限規程及び資金管理規程に従い、必要な承認を得て行う。

2. 会社財産を金融機関その他第三者に担保として提供する場合は、取締役会の承認を得なければならない。

### 第19条（財産の取得及び処分）

資産の取得、投資、出資、貸付、保証、固定資産の処分その他財産の取得又は処分に関する事項は、職務権限規程、稟議規程、固定資産管理規程及び関連する規程に従う。

### 第20条（特別な支出）

寄付、履行保証、予算外支出、通常取引と異なる支出その他特別な支出については、職務権限規程及び稟議規程に従い、必要な承認を得る。

## 第4章　決算

### 第21条（決算の目的）

決算は、会社の財政状態及び経営成績を明らかにし、会社法、法人税法その他関係法令に基づく外部報告の要請に応えるとともに、その内容の分析検討を通じて経営管理及び上場準備に資することを目的とする。

### 第22条（月次決算、四半期決算及び期末決算）

当社は、月次決算、四半期決算及び期末決算を行う。

2. 月次実績は、原則として翌月20日までに会計資料及び予算管理資料へ反映する。

3. 管理部は、将来的に月次決算の早期化を図り、取締役会及び経営会議への適時報告ができる体制を整備する。

### 第23条（決算日程）

経理責任者は、社内及び社外への迅速な報告を実現するため、関係部門、税理士、監査法人その他外部専門家と調整し、合理的な決算日程を策定する。

### 第24条（決算整理）

経理責任者は、決算にあたり、未収入金、売掛金、未払金、未払費用、前払費用、固定資産、減価償却、引当金、税金、売上計上、費用計上その他決算整理事項を確認し、決算数値を確定させる。

### 第25条（決算報告）

経理責任者は、月次、四半期及び期末の決算書類を取りまとめ、代表取締役社長、経営会議及び取締役会に報告する。

2. 重要な差異、通期業績見込への影響、資金繰りへの影響又は内部統制上の重要な不備がある場合は、速やかに代表取締役社長、経営会議及び取締役会に報告する。

3. 月次決算の確認者は、柿塚とする。

### 第26条（決算書類）

月次決算、四半期決算及び期末決算において作成又は確認する書類は、次のとおりとする。

1. 貸借対照表
2. 損益計算書
3. 月次推移表
4. 事業別損益資料
5. 予実管理資料
6. 資金繰り資料
7. 取締役会又は経営会議への報告資料
8. 税務申告書及び税務決算書類
9. その他経理責任者が必要と認める書類

## 第5章　税務

### 第27条（税務会計）

税務会計とは、納税に関する一切の経理処理及び手続をいい、税金に関する法令に準拠し、適正な申告及び納税を期限内に行う。

### 第28条（税務責任者）

経理責任者は、当社の税務を統括し、税務処理上疑義のある事項については、税理士、所轄税務署その他外部専門家と協議のうえ、適切に対応する。

### 第29条（税務調査）

経理責任者は、税務調査に際しては、税理士その他外部専門家の協力を得て、誠意をもって必要資料の提出又は説明を行う。

## 第6章　実施規程等

### 第30条（関連規程）

本規程の実施に必要な手続の細部については、職務権限規程、稟議規程、資金管理規程、固定資産管理規程、購買管理規程、販売管理規程、外注管理規程、文書管理規程その他関連規程による。

### 第31条（改廃）

本規程の改廃は、規程管理規程に基づき、取締役会の決議により行う。
