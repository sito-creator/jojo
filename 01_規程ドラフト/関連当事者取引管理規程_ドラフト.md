## 第1章 総則

### 第1条（目的）

本規程は、株式会社MoMo（以下「当社」という。）における関連当事者との取引について、当社と特別な関係を有する相手方との取引であることに伴う利益相反、取引条件の歪み、不公正な利益移転、不要な取引の強要その他のリスクを適切に牽制し、取引の合理性、公正性及び透明性を確保することを目的とする。

2. 当社は、上場準備及び上場後の開示実務を見据え、関連当事者及び関連当事者取引を適切に把握、承認、記録、管理及び開示検討する。

### 第2条（定義）

本規程における用語の定義は、次のとおりとする。

1. 「関連当事者取引」とは、当社又は当社の子会社等と関連当事者との取引をいい、対価の有無にかかわらず、資産、負債、資金、権利、役務、情報、機会その他経済的価値の移転又は提供をいう。
2. 「関連当事者取引」には、関連当事者が第三者のために当社との間で行う取引、当社と第三者との間の取引で関連当事者が当該取引に重要な影響を及ぼしているもの、及び関連当事者との間接的な取引を含む。
3. 「関連当事者」とは、法令、会計基準、上場準備上の開示実務その他必要な基準に照らし、当社と支配、被支配、重要な影響、人的関係、資本関係又は親族関係を有する者をいう。
4. 「近親者」とは、二親等内の親族その他会計基準又は開示実務上関連当事者として把握すべき親族をいう。
5. 「主要株主」とは、自己又は他人の名義をもって当社の議決権の10％以上を保有する株主その他当社に重要な影響を及ぼす株主をいう。

### 第3条（関連当事者の範囲）

関連当事者には、次の各号に掲げる者を含む。

1. 当社の親会社、子会社、関連会社その他関係会社
2. 当社と同一の親会社をもつ会社
3. 当社が他の会社の関連会社である場合における当該他の会社並びに当該会社の親会社及び子会社
4. 当社の主要株主及びその近親者
5. 当社の役員及びその近親者
6. 当社の親会社、重要な子会社又は重要な関係会社の役員及びその近親者
7. 前各号に掲げる者が議決権の過半数を自己の計算において所有している会社及びその子会社
8. 当社の役員又は主要株主が実質的に支配し、又は重要な影響を及ぼしている会社、団体又は個人事業
9. 従業員のための企業年金で、当社と重要な取引を行うもの
10. その他管理部又は関連当事者取引管理責任者が関連当事者として把握すべきと判断した者

### 第4条（対象取引）

本規程の対象となる取引には、次の各号に掲げる取引を含む。

1. 物品、サービス、研修、開発、SaaS、ライセンス、OEMその他役務の提供又は受領
2. 仕入、購買、外注、業務委託、顧問、コンサルティング、講師委託その他契約
3. 資産の売買、譲渡、賃貸借、使用許諾、無償利用、知的財産又はデータの利用
4. 資金の貸付、借入、立替、債権債務の発生、債務免除、担保提供、保証又は被保証
5. 出資、増資、新株予約権、株式譲渡その他資本政策に関する取引
6. 役員報酬、顧問料、業務委託料、紹介料、手数料その他経済的利益の提供
7. 関連当事者が関与する第三者との取引
8. 有償又は無償を問わず、当社又は関連当事者に経済的影響を与える取引

## 第2章 関連当事者取引管理

### 第5条（主管部署及び管理責任者）

関連当事者取引管理の主管部署は、管理部とする。

2. 関連当事者取引管理責任者は、代表取締役社長又は代表取締役社長が指名する者とする。現時点では具体名は未定とし、初期運用では管理部主管、最終確認は代表取締役社長が行う。

3. 管理部は、関連当事者リスト、関連当事者調査票、取引照会、承認記録、継続確認及び開示検討資料を管理する。

### 第6条（関連当事者リスト）

管理部は、事業年度ごとに、関連当事者に該当する者を記載した関連当事者リストを作成する。

2. 関連当事者リストは、事業年度終了後速やかに作成又は更新し、役員、主要株主、関係会社、近親者その他重要事項に異動があった場合には、その都度修正する。

3. 初期運用では、当社の代表取締役社長、取締役、監査役候補、主要株主、追加取締役候補、外部監査役候補及びこれらの近親者又は支配会社を優先して把握する。

4. 関連当事者リストに含まれる個人情報は、個人情報保護規程及び情報セキュリティ管理規程に従い、漏えいを防止し、適切に管理しなければならない。

### 第7条（関連当事者調査票）

管理部は、現任取締役、追加取締役候補、監査役候補、主要株主その他必要な者に対して、少なくとも年1回、関連当事者調査票の提出を求める。

2. 関連当事者調査票では、次の事項を確認する。

1. 本人、近親者及び支配会社の状況
2. 兼職、役員就任、顧問、業務委託、出資、株式保有その他人的又は資本的関係
3. 当社との取引、貸借、保証、担保、紹介料、手数料、顧問契約その他経済的関係
4. 当社との利益相反、競業、特別利害関係又はその可能性
5. 関連当事者リストの作成及び開示検討に必要な事項

3. 調査対象者は、管理部から調査依頼があった場合、正確かつ速やかに回答しなければならない。

4. 調査対象者は、近親者、支配会社、兼職、保有株式、取引関係その他調査票記載事項に重要な変更が生じた場合、速やかに管理部へ報告しなければならない。

### 第8条（関連当事者取引の事前把握）

当社が新たに取引を行う場合、取引担当者は、取引開始前に、取引相手又は当該取引に重要な影響を及ぼす者が関連当事者に該当しないかを確認し、関連当事者に該当する可能性がある場合は管理部へ照会しなければならない。

2. 関連当事者該当性が不明な場合、取引担当者は自己判断で取引を開始してはならず、管理部へ照会する。

3. 管理部は、関連当事者リスト、調査票、取引先情報、登記情報、契約情報その他必要資料に基づき、関連当事者取引に該当するか確認し、必要な対応を取引担当者へ指示する。

### 第9条（関連当事者取引の承認）

管理部の照会又は確認の結果、関連当事者と新たに取引を行う場合には、原則として取締役会の承認を得なければならない。

2. 取締役会承認にあたっては、次の事項を確認する。

1. 関連当事者の内容及び当社との関係
2. 取引の合理性及び事業上の必要性
3. 価格、期間、支払条件、契約条件その他取引条件の妥当性
4. 関連当事者以外との取引条件との比較
5. 代替取引先又は代替手段の有無
6. 当社及び株主共同の利益への影響
7. 利益相反、競業、特別利害関係の有無
8. 開示、監査、上場準備又はレピュテーション上の影響

3. 取引の合理性又は取引条件の妥当性に疑義がある場合、管理部又は関連当事者取引管理責任者は、必要に応じて弁護士、公認会計士、税理士その他外部専門家と協議する。

4. 関連当事者取引に特別利害関係を有する取締役は、当該取締役会の審議及び決議に参加してはならない。

5. 監査役が設置されている場合、取締役会は、当該関連当事者取引の合理性及び取引条件の妥当性について、監査役の意見を求めるものとする。

6. 取引開始後に取引内容、金額、期間、条件又は相手方を重要に変更する場合も、本条の規定を準用する。

### 第10条（承認の例外及び報告）

前条にかかわらず、関連当事者以外と行っている通常取引と同等の条件であり、かつ当社への影響が軽微な取引については、管理部及び関連当事者取引管理責任者の確認により、取締役会承認に代えて経営会議又は取締役会への報告とすることができる。

2. 前項の軽微な取引の初期基準は、年間取引予定額が10万円未満、又は一時的かつ少額で当社の意思決定に重要な影響を与えない取引とする。ただし、貸付、借入、保証、担保提供、役員報酬、顧問契約、株式又は新株予約権に関する取引、知的財産又は重要な情報資産に関する取引は、金額にかかわらず原則として取締役会承認の対象とする。

3. 承認例外とした場合でも、管理部は、判断理由、取引条件、金額及び関連当事者該当性を記録する。

### 第11条（関連当事者取引継続の確認）

管理部又は関連当事者取引管理責任者は、毎事業年度末時点で継続している関連当事者取引について、取引継続の合理性、事業上の必要性及び取引条件の妥当性を確認する。

2. 継続している関連当事者取引は、新たな事業年度開始後最初に開催する取締役会又は経営会議に報告し、必要に応じて取締役会の継続承認を得る。

3. 関連当事者取引の継続に合理性又は条件の妥当性が認められない場合、管理部は、条件変更、解消、代替取引先への変更その他必要な対応を検討する。

### 第12条（開示要否の検討）

関連当事者取引が承認され、又は継続確認された場合、管理部は、計算書類、事業報告、招集通知、有価証券報告書、上場申請書類、証券会社又は取引所提出資料その他開示資料への記載要否を検討する。

2. 開示要否の検討にあたっては、必要に応じて監査法人、公認会計士、弁護士、税理士、上場支援会社、証券会社その他外部専門家に相談する。

3. 当社が上場企業ではない期間においても、株主総会招集通知、計算書類、事業報告、上場準備資料その他必要な資料への記載又は説明の要否を意識して管理する。

## 第3章 その他特定の者との取引

### 第13条（その他特定の者）

関連当事者に含まれない場合であっても、当社と人的、資本的、取引上又は資金上の関係を強く有し、利益相反又は取引条件の歪みが生じるおそれがある者（以下「その他特定者」という。）との取引については、本規程を準用する。

2. その他特定者には、次の者を含む。

1. 当社の役員が20％以上の議決権を有する法人
2. 当社の特別利害関係人とみなされる者
3. 人事、資金、取引その他の関係を通じて当社を支配し、又は当社に重要な影響を及ぼす者
4. 上場時又は上場準備に関与する証券会社、上場支援会社その他専門家及びその役員で、取引条件の公正性確認が必要な者
5. その他管理部又は関連当事者取引管理責任者が本規程を準用すべきと判断した者

### 第14条（禁止事項）

当社は、次の各号に掲げる関連当事者取引又はその他特定者との取引を行ってはならない。

1. 当社に不利益を与える取引
2. 合理性又は事業上の必要性を説明できない取引
3. 価格その他条件が第三者取引と比較して不公正な取引
4. 役員、主要株主、近親者又は支配会社への不当な利益移転となる取引
5. 取締役会の承認を得るべきであるにもかかわらず、承認を得ずに行う取引
6. 法令、定款、社内規程、上場準備上の内部管理体制又は公序良俗に反する取引

## 第4章 記録及び保存

### 第15条（記録）

管理部は、関連当事者リスト、関連当事者調査票、取引照会記録、取引確認資料、取締役会議事録、経営会議議事録、契約書、価格妥当性資料、外部専門家への相談記録、開示要否検討資料その他関連当事者取引に関する資料を保存管理する。

2. 関連当事者取引の承認又は報告に関する資料には、取引の合理性、事業上の必要性、取引条件の妥当性、特別利害関係取締役の有無及び開示要否の検討結果を記録する。

### 第16条（保存期間）

関連当事者取引管理に関する資料の保存期間は、原則として10年とする。ただし、法令、契約又は他の規程によりこれを超える保存期間が定められている場合は、その定めによる。

### 第17条（報告）

管理部は、関連当事者の状況、関連当事者取引の有無、承認状況、継続取引の見直し結果、開示要否の検討結果その他重要事項を、必要に応じて経営会議及び取締役会に報告する。

2. 現時点で、当社は既存の関連当事者取引を把握していない。今後、関連当事者取引が判明し、又は発生する場合は、本規程に基づき管理部へ報告し、必要な承認又は報告を行う。

## 第5章 違反時の措置

### 第18条（違反時の措置）

役員、従業員又は外注先等が本規程に違反し、又は関連当事者取引に関する報告、調査票、照会若しくは承認手続を怠った場合、当社は就業規則、契約条件、会社法その他関係法令及び社内規程に基づき、是正要求、懲戒、契約解除、損害賠償請求その他必要な措置を講じることがある。

## 第6章 改廃

### 第19条（改廃）

本規程の改廃は、規程管理規程に従い、取締役会の決議により行う。
