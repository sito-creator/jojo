## 第1章 総則

### 第1条（目的）

本規程は、株式会社MoMo（以下「当社」という。）における文書の作成、取得、整理、保管、保存、閲覧、持出し、引継ぎ及び廃棄に関して必要な事項を定め、文書に関する業務の正確化及び円滑化を図るとともに、文書の取扱いに起因する情報漏えい、紛失、改ざん、証跡欠落その他のリスクを防止することを目的とする。

### 第2条（定義）

本規程における用語の定義は、次のとおりとする。

1. 「文書」とは、当社の業務上の必要に応じて作成、取得、収集、参照、保存又は提出される書類、図面、写真、電子メール、チャット、議事録、稟議記録、契約書、請求書、証憑、台帳、スプレッドシート、音声、動画、画像、磁気媒体、クラウド上の記録その他電磁的記録をいう。
2. 「情報文書」とは、文書のうち、個人情報、顧客情報、契約情報、会計情報、未公開の経営情報、開発情報、ソースコード、認証情報、営業秘密その他漏えい又は不適切な開示により当社又は第三者に損害を与えるおそれがあるものをいう。
3. 「文書管理業務」とは、文書の作成、取得、整理、保管、保存、閲覧、共有、持出し、引継ぎ、廃棄その他文書の取扱いに関する業務をいう。
4. 「保存」とは、法令、契約、社内規程又は業務上の重要性に基づき、文書を一定期間保有することをいう。
5. 「保管」とは、所管部門で使用されている文書を格納し、管理している状態をいう。
6. 「所管部門」とは、文書の作成、取得、利用又は保存について主管する部門をいう。

### 第3条（私有禁止）

文書は、すべて当社に帰属するものとし、役員、従業員、外注先その他当社業務に従事する者は、文書を私有してはならない。

2. 私用アカウント、私用ストレージ、個人端末その他当社が認めない環境に業務文書を保存してはならない。

### 第4条（機密の保持）

役員、従業員、外注先その他当社業務に従事する者は、文書管理業務を通じて業務上知り得た企業秘密、個人情報、顧客情報、開発情報その他重要な情報を、正当な権限なく利用し、又は第三者に漏えいしてはならない。

2. 情報文書の取扱いについては、本規程のほか、情報セキュリティ管理規程、個人情報保護規程、システム管理規程及び外注管理規程に従う。

## 第2章 文書管理の組織

### 第5条（文書管理統括部門）

当社における文書管理を統括する部門は、管理部とする。

2. 管理部は、文書管理に関する基本方針、保存期間、保存場所、廃棄方法、アクセス権限、文書管理台帳その他文書管理に必要な事項を統括する。

### 第6条（文書管理責任者及び担当者）

各所管部門の責任者を文書管理責任者とし、当該所管部門における文書管理の適切な実施について責任を負う。

2. 文書管理責任者は、必要に応じて文書管理担当者を指名することができる。

3. 文書管理責任者及び文書管理担当者は、管理部と連携し、文書の整理、保管、保存、引継ぎ、廃棄及びアクセス権限の管理を行う。

## 第3章 文書の取扱い

### 第7条（文書の作成及び取得）

文書を作成又は取得する者は、内容の正確性、作成日、作成者、所管部門、承認状況、関連資料及び保存場所が確認できるようにしなければならない。

2. 重要な文書については、承認権限、版数、改定履歴、関連する稟議、議事録、契約又は証憑との関係を明確にする。

### 第8条（文書の引継ぎ）

組織変更、担当変更、退職、業務委託終了その他の理由により文書を他の部署又は担当者に引き継ぐ場合、文書管理責任者は、対象文書、保存場所、アクセス権限、未処理事項及び機密保持に十分注意して引継ぎを行わなければならない。

2. 重要な情報文書を引き継ぐ場合は、必要に応じて引継ぎ記録を作成する。

### 第9条（情報文書の使用）

情報文書は、原則として当社が認めた保管場所、業務システム、クラウドサービス又は執務場所において使用しなければならない。

2. 情報文書を閲覧、共有又は編集する場合は、業務上必要な者に限定し、アクセス権限を適切に設定する。

### 第10条（情報文書の持出し）

情報文書を社外へ持ち出し、又は社外からアクセスできる状態にすることは、原則として禁止する。

2. 業務上やむを得ず情報文書を持ち出し、又は社外からアクセスする場合は、必要最小限の範囲とし、文書管理責任者又は管理部の確認を受けるものとする。

3. 持出し又は社外アクセスを行う場合は、紛失、盗難、誤送信、閲覧権限の過大付与、不正アクセス、第三者閲覧及び情報漏えいを防止するため、パスワード、暗号化、アクセス制限、共有期限、端末管理その他必要な措置を講じる。

### 第11条（電子文書及び電子原本）

当社は、法令、契約又は取引実務上書面原本が必要な場合を除き、電子文書を正本又は保存文書として取り扱うことができる。

2. 電子文書を正本又は保存文書として取り扱う場合は、作成者、作成日、承認履歴、改定履歴、アクセス権限及び保存場所が確認できるようにする。

3. Word、PDF、スプレッドシート、Notionページ、マネーフォワード上の証憑、電子契約データその他電子文書は、改ざん防止、閲覧権限、版管理及びバックアップに留意して管理する。

## 第4章 文書の整理及び保管

### 第12条（文書の整理）

文書は、その内容及び所管部門に応じた適切な方法により整理し、処理済みのものと処理未了のものの区別を明らかにしておかなければならない。

2. 重要文書は、検索性、証跡性及び閲覧権限に留意し、文書名、作成日、対象年度、取引先名、案件名、版数その他識別に必要な情報を付して保存する。

### 第13条（文書の保管）

文書の保管は、文書管理責任者が行う。

2. 文書管理責任者は、所管文書について、保存場所、アクセス権限、保存期間及び廃棄予定を把握する。

### 第14条（文書の保管場所）

文書の保管場所は、当面、次の各号に掲げる場所を基本とする。

1. 取締役会、経営会議、稟議、規程、組織、業務分掌、職務権限、内部監査、反社チェック、与信、外注先管理、関連当事者、クレームその他管理記録：Notion又は管理部が指定する場所
2. 契約書、見積書、請求書、経費精算、会計証憑、入出金、購買、外注、給与関連資料：マネーフォワード、Google Drive又は管理部が指定する場所
3. 予算、予実、事業別管理資料、KPI、事業計画、月次資料：Google Drive、Google Sheets、Notion又は管理部が指定する場所
4. 開発情報、ソースコード、仕様書、設計資料、AI関連データ、SaaS運用資料：リポジトリ、開発環境、Google Drive、Notion又は管理部が指定する場所
5. 書面原本が必要な契約書、登記関係書類、印鑑関係書類、法定書類その他重要書類：施錠できるキャビネット、金庫、外部保管サービス又は管理部が指定する場所

2. 書面による情報文書その他重要文書は、施錠できるキャビネット、金庫その他安全な場所に保管する。

3. 鍵、管理者権限及び外部保管サービスの利用権限は、管理部又は文書管理責任者が厳重に管理する。

### 第15条（アクセス権限）

電子文書の閲覧、編集、共有及び削除権限は、業務上必要な範囲に限定する。

2. 退職、異動、担当変更、業務委託終了その他アクセス権限の変更が必要な場合、文書管理責任者は、管理部又はシステム管理責任者と連携して速やかに権限を変更又は削除する。

3. 重要文書の共有リンクを発行する場合は、共有範囲、期限、閲覧権限及びダウンロード可否に留意する。

### 第16条（文書管理台帳）

管理部は、必要に応じて、重要文書の文書名、所管部門、保存場所、保存期間、アクセス権限、作成日、改定日、廃棄予定日その他必要事項を記録した文書管理台帳を整備する。

2. 初期運用では、規程、議事録、稟議、契約書、重要証憑、個人情報関連記録、情報セキュリティ記録、内部監査記録その他上場準備上重要な文書を優先して台帳管理する。

## 第5章 文書の保存

### 第17条（文書の保存）

保存文書の保存は、文書管理責任者が行う。

2. 保存文書は、保存期間、対象年度、所管部門及び保存場所が分かるように管理する。

### 第18条（文書の保存期間）

文書の保存期間は、別表「文書保存期間基準」による。

2. 別表に定めのない文書の保存期間は、法令、契約、業務上の重要性、上場準備上の必要性及び関連規程を踏まえ、管理部又は文書管理責任者が定める。

3. 法令又は契約により別表より長い保存期間が求められる場合は、当該法令又は契約に従う。

### 第19条（他の媒体による保存）

保存文書は、数量、保存期間、検索性、証拠能力及び情報セキュリティを考慮し、必要と認められる場合には、当該文書の内容を保存に適した媒体に記録したものを保存することができる。

2. 書面文書を電子化して保存する場合は、原本性、改ざん防止、閲覧権限、バックアップ及び検索性に留意する。

3. 法令上、電子帳簿保存法その他の要件が適用される文書については、法令及び経理規程に従う。

## 第6章 文書の廃棄

### 第20条（文書の廃棄）

文書管理責任者は、少なくとも年1回、保存期間の満了した文書、保管又は保存の不要となった文書その他廃棄可能な文書を確認し、必要に応じて廃棄する。

2. 重要文書、情報文書、個人情報を含む文書又は法定保存文書を廃棄する場合は、保存期間満了、廃棄可否及び廃棄方法を確認する。

3. 紛争、監査、税務調査、上場審査、内部調査その他の理由により保存が必要な文書は、保存期間が満了していても廃棄してはならない。

### 第21条（情報文書の廃棄方法）

情報文書の廃棄は、復元困難な方法により行う。

2. 紙文書は、シュレッダー処理、溶解処理、焼却その他復元困難な方法により廃棄する。

3. 電子文書、記録媒体、端末、クラウド上のデータは、データ消去、アクセス権限削除、アカウント削除、初期化、物理破壊その他復元困難な方法により廃棄又は削除する。

4. 廃棄又は削除を外部業者に委託する場合は、委託先、対象文書、授受、廃棄方法及び廃棄証明の取得を確認する。

### 第22条（廃棄記録）

管理部又は文書管理責任者は、重要文書、情報文書、個人情報を含む文書その他必要な文書を廃棄した場合、廃棄日、対象文書、廃棄方法、実施者、確認者及び廃棄証明の有無を記録する。

## 第7章 点検及び違反時対応

### 第23条（点検）

管理部又は文書管理責任者は、少なくとも年1回、文書の保存場所、アクセス権限、保存期間、廃棄状況、重要文書の所在及び電子文書の管理状況を点検する。

2. 内部監査責任者は、内部監査規程及び内部監査計画に従い、文書管理の整備及び運用状況を監査する。

### 第24条（違反時の措置）

本規程に違反した者に対しては、就業規則、契約条件その他社内規程に基づき、懲戒、是正要求、契約解除、損害賠償請求その他必要な措置を講じることがある。

## 第8章 改廃

### 第25条（改廃）

本規程の改廃は、規程管理規程に従い、取締役会の決議により行う。

## 要確認事項

- 契約書原本の有無、紙原本の保管場所、電子契約の利用状況を確認する。
- Google Drive、Notion、マネーフォワードのフォルダ/ページ設計とアクセス権限管理者を確認する。
- 文書保存期間基準を法務・税務・労務の専門家レビューに回す。
- 電子帳簿保存法対応の現状、マネーフォワード上の証憑保存運用を確認する。
- 文書管理台帳をNotionで開始するか、Google Sheetsで開始するか確認する。
- 廃棄証明を取得すべき文書及び外部廃棄業者の有無を確認する。

## 現時点の前提メモ

- 文書管理は管理部主管で設計する。
- 取締役会・経営会議資料、議事録、招集通知、確認記録はNotion保管を前提とする。
- 稟議・承認証跡はNotion、マネーフォワード、関連資料リンクを利用する。
- 見積書、契約書、請求書、経費精算等はマネーフォワードを利用する。
- 予算、予実、事業管理資料はGoogle Sheets及びGoogle Driveを利用する。
