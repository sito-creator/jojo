# 経営会議規程（ドラフト）

会社名：株式会社MoMo
制定日：YYYY年MM月DD日
改定日：-
主管部署：管理部
承認機関：取締役会

## 第1章 総則

### 第1条（目的）

本規程は、当社の経営に関する重要事項について審議、協議及び報告を行い、経営の適正かつ効率的な運営を確保するため、経営会議（以下「本会議」という。）の組織及び運営に関する基本事項を定めることを目的とする。

### 第2条（位置付け）

本会議は、取締役会及び代表取締役社長を補佐する会議体として、取締役会が決議すべき事項を除き、経営に関する重要事項を審議、協議及び報告する。

2. 取締役会の決議を要する事項については、本会議での審議を経たうえで取締役会へ付議する。

3. 本会議は、法令又は定款に基づく取締役会の権限を代替するものではない。

## 第2章 構成

### 第3条（構成員）

本会議の構成員は、次のとおりとする。

1. 代表取締役社長
2. 管理部門責任者
3. 各事業責任者
4. その他代表取締役社長が指名する者

2. 本会議の議長は、代表取締役社長が務める。

3. 監査役は、必要に応じて本会議に出席し、意見を述べることができる。

### 第4条（事務局）

本会議の事務局は、管理部とする。

### 第5条（関係者の出席）

議長は、必要があると認めたときは、構成員以外の者を本会議に出席させ、説明又は意見を求めることができるほか、必要な報告を行わせることができる。

## 第3章 開催

### 第6条（開催頻度）

本会議は、原則として毎月1回開催する。ただし、議長が必要と認めた場合は、臨時で開催することができる。

2. 月次決算及び予実管理を報告する本会議は、原則として月次決算及び予実管理資料の作成後、速やかに開催する。

### 第7条（招集及び議案提出）

本会議は、議長が招集する。

2. 本会議に付議又は報告する議案は、構成員又は関係部署の責任者が提出することができる。

3. 議案の提出は、原則としてNotion上の議事進行シート又は事務局が指定する方法により行うものとし、会議開催前までに必要事項及び関連資料を記録するものとする。

4. 月次決算及び予実管理に関する資料は、原則として翌月20日までに実績を反映したうえで、本会議に提出する。

## 第4章 運営の要領

### 第8条（協議事項）

本会議で審議又は協議する事項は、次のとおりとする。

1. 取締役会付議事項に関する事前審議
2. 経営方針、事業計画、中期経営計画に関する事項
3. 年度予算、予算修正、月次決算、予実差異に関する事項
4. 重要な投資、資本政策、資金調達、資金運用に関する事項
5. 重要な組織変更、人事政策、採用に関する事項
6. 重要な販売、購買、外注、与信に関する事項
7. リスク管理、コンプライアンス、クレーム、事故、不祥事に関する事項
8. 内部統制、内部監査、監査役監査、外部専門家による指摘事項及び改善状況に関する事項
9. その他議長が必要と認める事項

### 第9条（定足数）

本会議は、構成員の過半数の出席をもって成立する。

### 第10条（決議）

本会議において決議を要する事項は、職務権限規程及び決裁権限基準表の定めによる。

2. 本会議において決議を必要とするときは、出席者全員の同意をもって決定する。ただし、欠席した構成員に対しては、決議後速やかに決議内容を通知し、必要に応じて追認を求めるものとする。

### 第11条（持ち回り）

緊急を要する事項については、議長の判断により、書面又は電磁的方法による持ち回りにより決議を行うことができる。

2. 前項の方法により決議を行う場合は、構成員全員の同意をもって決議があったものとみなす。

## 第5章 議事録

### 第12条（議事録の作成及び保管）

本会議の議事内容は、Notion上の議事進行シート又は事務局が指定する方法により記録し、電磁的記録として保存するものとする。

2. 議事進行シート又は議事録には、次の事項を簡潔に記録するものとする。

1. 開催日時及び場所又は開催方法
2. 出席者の所属及び氏名
3. 議事の要旨
4. 決議をした場合はその内容
5. 継続検討事項、担当者及び期限
6. その他特記事項

3. 議事録の作成担当者は、事務局が議案及び稟議内容を踏まえて定める。

4. 本会議で使用した資料についても、電磁的記録をもって議事録とともにNotionに保存するものとする。

5. 出席者による議事録の確認は、当面はNotion上の確認記録により行う。

### 第13条（改廃）

本規程の改廃は、規程管理規程による。

## 付則

## 現時点の前提メモ

- 経営会議メンバーは、代表取締役社長、管理部門責任者、各事業責任者を初期案とする。
- 月次決算及び予実管理を報告する経営会議は、月次決算完了後すぐ開催し、必要事項を取締役会へ上程する。
- 取締役会への上程基準は、100万円以上の重要支出、重要契約、重要外注、借入、投資その他重要事項を原則とする。
- 議事録の作成担当者は、議案及び稟議内容に応じて設定する。
- 経営会議の議事録、付議資料及び確認記録はNotionに保存する。
- 議事録の確認は、当面はNotion上の確認記録で進める。
