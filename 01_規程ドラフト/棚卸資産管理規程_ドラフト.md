# 棚卸資産管理規程（ドラフト）

会社名：株式会社MoMo

施行日：YYYY年MM月DD日

## 第1章　総則

### 第1条（目的）

本規程は、株式会社MoMo（以下「当社」という。）における棚卸資産の取得、保管、使用、販売、廃棄、実地棚卸及び会計処理に関する基本事項を定め、棚卸資産の適正な管理及び財務報告の信頼性を確保することを目的とする。

### 第2条（適用範囲）

本規程は、当社が保有する棚卸資産及び棚卸資産に該当する可能性のある物品、教材、端末、販促物、販売用ライセンス、仕掛品その他これらに類する資産に適用する。

2. 当社が棚卸資産を保有しない期間においては、管理部が会計年度ごとに棚卸資産の有無を確認し、確認記録を保存する。

3. PC、スマートフォン、開発機材、ソフトウェア、ライセンス、敷金保証金その他固定資産又は物品として管理すべきものは、固定資産管理規程又は購買管理規程に従う。

### 第3条（棚卸資産の定義）

本規程における棚卸資産とは、販売、役務提供、制作、研修、開発又はこれらに付随する業務のために保有する資産のうち、会計上棚卸資産として処理すべきものをいう。

2. 棚卸資産に該当する可能性があるものは、次のとおりとする。

1. 販売又は有償提供を目的として保有する物品、端末、教材、冊子、カード、備品その他商品
2. AI研修、AI伴走、OEM、AI受託開発、SaaS、キャリアコーチングその他当社サービスに関連して販売又は配布する教材、制作物又は仕掛品
3. 顧客納品前の成果物、開発中プロダクト、制作途中のコンテンツその他原価計算上棚卸資産として管理すべきもの
4. その他管理部が棚卸資産として管理すべきと判断したもの

### 第4条（管理部門）

棚卸資産の管理主管部門は、管理部とする。

2. 棚卸資産を保有又は使用する部門の責任者は、管理部と連携し、棚卸資産の取得、保管、使用、販売、廃棄、棚卸及び報告を適切に行わなければならない。

### 第5条（管理責任者）

管理部は、棚卸資産の管理責任者を定める。

2. 棚卸資産管理責任者は、棚卸資産台帳、実地棚卸、差異処理、評価、廃棄及び会計処理に関する管理を統括する。

## 第2章　取得及び保管

### 第6条（取得手続）

棚卸資産を取得する場合、取得を希望する部門は、目的、数量、単価、総額、保管場所、使用又は販売予定、収益見込み及び原価処理方針を明らかにし、購買管理規程、外注管理規程、稟議規程及び職務権限規程に従い承認を得なければならない。

2. 10万円以上の取得又は制作を行う場合、原則として事前に代表取締役社長の承認を得る。

3. 50万円以上又は重要な事業計画に関係する棚卸資産を取得又は制作する場合、経営会議へ報告し、必要に応じて取締役会へ付議する。

### 第7条（受入及び検収）

棚卸資産を受け入れた部門は、数量、品質、仕様、納期、契約条件及び請求内容を確認し、検収記録を作成する。

2. 検収記録は、Notion、Google Drive、マネーフォワードその他会社が指定する方法により保存する。

3. 受入内容に不備、数量差異、破損、品質不良又は仕様不一致がある場合、受入部門は速やかに管理部及び発注先へ報告し、返品、交換、補修、値引又は再納品その他必要な対応を行う。

### 第8条（棚卸資産台帳）

管理部は、棚卸資産を保有する場合、棚卸資産台帳を作成し、次の事項を記録する。

1. 品目名、管理番号及び区分
2. 取得日、取得先、取得数量及び取得価額
3. 保管場所及び保管責任者
4. 入出庫、使用、販売、廃棄その他数量の増減
5. 実地棚卸結果及び差異
6. 評価減、廃棄、滞留その他管理上重要な事項

2. 棚卸資産台帳は、Notion、Googleスプレッドシート、マネーフォワードその他会社が指定する方法により管理する。

### 第9条（保管）

棚卸資産を保管する部門は、棚卸資産の紛失、盗難、破損、劣化、誤使用、私的利用及び無断持出しを防止するため、適切な保管場所、アクセス権限及び管理方法を定める。

2. 個人情報、顧客情報、ソースコード、AI関連データその他秘密情報を含む棚卸資産又は成果物については、情報セキュリティ管理規程、個人情報保護規程及び文書管理規程に従い管理する。

## 第3章　入出庫、販売及び使用

### 第10条（入出庫管理）

棚卸資産の入庫、出庫、使用、販売、配布、移動又は廃棄を行う場合、担当部門は、数量、日付、目的、相手先、担当者及び承認者を記録する。

2. 棚卸資産の出庫又は配布は、業務上必要な範囲で行い、私的利用又は無断使用をしてはならない。

### 第11条（販売又は提供）

棚卸資産を顧客へ販売又は提供する場合、販売管理規程、与信管理規程、稟議規程及び職務権限規程に従い、見積、契約、納品、売上計上、請求及び代金回収を行う。

2. 無償提供、値引、返品、返金又は交換を行う場合、担当部門は、理由及び承認記録を保存する。

### 第12条（原価計算）

棚卸資産に関する取得価額、制作原価、外注費、材料費その他原価は、経理規程及び会計方針に従い、適切に集計、配賦及び処理する。

2. AI受託開発、OEM、SaaS開発、教材制作その他仕掛品が発生する可能性がある案件については、管理部が必要に応じて原価計算の要否を判断する。

3. 原価計算方法を変更する場合、管理部は、税理士、公認会計士、監査法人又は上場支援会社に確認する。

## 第4章　実地棚卸

### 第13条（実地棚卸）

当社が棚卸資産を保有する場合、管理部は、原則として会計年度末及び必要に応じて実地棚卸を実施する。

2. 棚卸資産を保有しない期間においても、管理部は、会計年度末に棚卸資産の有無を確認し、その結果を記録する。

3. 実地棚卸の具体的な手順は、棚卸実施要領に定める。

### 第14条（棚卸差異）

実地棚卸の結果、帳簿数量と実在数量に差異が生じた場合、管理部及び担当部門は、差異の原因を調査し、必要な修正、再発防止、評価減、廃棄又は会計処理を行う。

2. 重要な差異、紛失、不正利用、盗難又は情報漏えいのおそれがある場合、管理部は、経営会議へ報告し、必要に応じて取締役会へ報告又は付議する。

### 第15条（評価）

管理部は、棚卸資産の販売可能性、使用可能性、陳腐化、破損、劣化、滞留、契約キャンセルその他の事情を確認し、評価減又は廃棄の要否を検討する。

2. 評価減又は廃棄を行う場合、管理部は、経理規程、会計方針及び税務上の取扱いを確認し、必要な承認を得る。

### 第16条（廃棄）

棚卸資産を廃棄する場合、担当部門は、品目、数量、理由、廃棄方法、廃棄予定日、会計処理及び情報消去の要否を明らかにし、管理部の承認を得る。

2. 10万円以上の棚卸資産の廃棄又は重要な情報を含む棚卸資産の廃棄については、代表取締役社長の承認を得る。

3. 廃棄を行った場合、廃棄記録、写真、廃棄証明書、情報消去証跡その他必要な証跡を保存する。

## 第5章　報告及び保存

### 第17条（報告）

管理部は、棚卸資産の保有状況、実地棚卸結果、重要な差異、滞留、評価減、廃棄その他重要事項について、必要に応じて経営会議へ報告する。

2. 財務報告、税務、監査又は上場準備上重要な事項については、取締役会へ報告又は付議する。

### 第18条（記録の保存）

棚卸資産台帳、取得記録、検収記録、入出庫記録、実地棚卸記録、差異調査、評価減、廃棄、会計処理その他棚卸資産に関する資料は、Notion、Google Drive、マネーフォワードその他会社が指定する方法により保存する。

2. 前項の資料の保存期間は、原則として10年とする。

### 第19条（改廃）

本規程の改廃は、規程管理規程に基づき、取締役会の決議により行う。
