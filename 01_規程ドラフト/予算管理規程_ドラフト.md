# 予算管理規程（ドラフト）

会社名：株式会社MoMo

施行日：YYYY年MM月DD日

## 第1章　総則

### 第1条（目的）

本規程は、株式会社MoMo（以下「当社」という。）の経営基本方針に基づく予算の編成、実行、管理、予実差異分析及び修正に関する事項を定め、計画的な経営活動、迅速な意思決定及び上場準備に必要な月次管理体制の整備を図ることを目的とする。

### 第2条（予算期間）

予算期間は、当社の会計年度と一致させ、毎年7月1日から翌年6月30日までの1年間とする。

2. 予算管理においては、年度、半期、四半期及び月次の区分を設ける。

### 第3条（予算体系）

年度予算は、部門別予算、事業別予算及びこれらに基づく総合予算により構成する。

2. 予算体系は、次のとおりとする。

1. 損益予算
2. 事業別予算
3. KPI予算
4. 人件費予算
5. 固定費予算
6. 投資予算
7. 資金予算
8. 採用計画
9. その他会社が必要と認める予算又は計画

### 第4条（事業別予算）

事業別予算は、次の事業区分を基本として作成する。

1. AI研修
2. AI伴走
3. OEM
4. AI受託開発
5. SaaS
6. キャリアコーチング
7. その他会社が必要と認める事業

### 第5条（KPI予算）

当社は、事業特性に応じて、売上高、受注件数、商談数、成約率、顧客数、単価、継続率、稼働数、案件進捗、リセラー数その他必要なKPI予算を設定する。

2. KPI予算は、損益予算及び事業別予算と整合させ、月次で実績と比較できる形式により管理する。

## 第2章　予算の管理組織

### 第6条（最高責任者）

予算管理の最高責任者は、代表取締役社長とする。

2. 代表取締役社長は、翌年度の経営基本方針及び予算編成方針を示し、それに沿った予算の編成を指示する。

### 第7条（統括責任者）

予算管理の統括責任者は、管理部門責任者とする。

2. 管理部門責任者が未選任又は不在の場合、代表取締役社長が予算管理の統括責任者を指名する。

3. 統括責任者の職務は、次のとおりとする。

1. 予算編成方針の立案
2. 予算編成日程の作成
3. 各部門及び各事業の予算案の調整
4. 総合予算案の編成
5. 予算の立案、執行及び管理に関する関係部門への助言
6. 月次実績及び予実差異の分析
7. 経営会議及び取締役会への報告資料の作成

### 第8条（部門予算責任者）

各部門の責任者を部門予算責任者とする。

2. 部門予算責任者は、担当部門又は担当事業の予算案の作成、予算の実行、月次実績の確認、KPI実績の確認及び予実差異分析に基づく改善対応を行う。

### 第9条（執行役員との関係）

執行役員制度を設ける場合、担当執行役員は、管掌部門の部門予算責任者に対し、予算の立案、実行及び管理に関する指示又は調整を行う。

2. 執行役員制度を設けない期間は、代表取締役社長、担当取締役又は会社が指定する者が前項の役割を担う。

### 第10条（取締役会及び経営会議との関係）

予算の編成、承認、重要な修正その他予算管理に関する重要事項は、経営会議において審議し、取締役会において決議する。

2. 事業別予算、KPI予算その他実務上の管理事項は、経営会議において審議し、代表取締役社長が承認することができる。ただし、年度予算又は中期経営計画に重要な影響を与える場合は、取締役会に付議する。

## 第3章　予算の編成

### 第11条（中期経営計画との関係）

当社は、上場準備及び成長戦略の観点から、中期的な経営方針、事業戦略、財務計画及びKPI計画を必要に応じて策定する。

2. 年度予算の編成にあたっては、中期経営計画又はこれに準じる経営方針と整合させる。

3. 中期経営計画を策定又は重要な変更を行う場合は、経営会議で審議したうえで、取締役会の決議により承認する。

### 第12条（予算編成方針）

年度予算の編成方針は、代表取締役社長の経営基本方針及び中期経営計画又はこれに準じる経営方針に基づき、統括責任者が立案する。

2. 予算編成方針は、経営会議で審議したうえで、取締役会の決議により決定する。

### 第13条（予算編成の手順）

統括責任者は、各部門予算責任者に対し、予算編成方針、提出期限、作成方法及び使用する管理資料を通知する。

2. 各部門予算責任者は、担当部門又は担当事業の売上、原価、人件費、固定費、投資、採用、KPIその他必要な予算案を作成し、統括責任者へ提出する。

3. 統括責任者は、提出された予算案を集計、調整し、総合予算案を編成して経営会議に提出する。

4. 統括責任者は、経営会議の審議を経た年度予算案を取締役会に付議する。

5. 統括責任者は、取締役会で承認された年度予算を各部門予算責任者に通知する。

### 第14条（管理資料）

予算管理に使用する管理資料は、全体予算管理資料及び事業別予算管理資料を基本とする。

2. 管理部は、管理資料の保存場所、更新担当、更新期限、閲覧権限及び版数を管理する。

3. 全体予算管理資料は、Dashboard、計画PL、実績PL、予実管理、営業KPI、固定費管理、人件費管理、配賦結果、統合DB_PL及び統合DB_KPIを基本構成とする。

4. 事業別予算管理資料は、事業計画、実績入力、予実管理又は営業予実管理、担当者別KPI、現場登録、出力_PL及び出力_KPIを基本構成とする。

## 第4章　予算の実行管理

### 第15条（予算の実施）

各部門予算責任者は、承認された部門別予算及び事業別予算に基づき、担当部門又は担当事業の業務を遂行する。

2. 予算の執行にあたっては、職務権限規程、稟議規程、購買管理規程、外注管理規程、販売管理規程その他関連規程に従い、必要な承認を得る。

### 第16条（月次実績）

管理部は、毎月、売上、原価、経費、営業利益、資金繰り、事業別KPIその他必要な実績を取りまとめる。

2. 月次実績は、原則として翌月20日までに管理資料へ反映する。

3. 各部門は、実績入力、現場登録、案件管理、顧客管理その他該当する管理資料に、月次実績及びKPI実績を入力又は報告する。

4. 管理部は、事業別管理資料の出力_PL、出力_KPI及び全体管理資料の統合DB_PL、統合DB_KPIを確認し、全体の月次実績に反映する。

### 第17条（予算・実績対比資料）

統括責任者は、実績と予算を対比した資料を月次で作成する。

2. 月次予実資料には、全体Dashboard、月次PL、事業別PL、予実差異、営業KPI、事業別KPI、固定費、人件費、資金繰り及び重要差異の原因・対応策を含める。

### 第18条（予算実績差異分析報告）

統括責任者は、予算と実績を比較検討し、必要に応じて各部門に確認したうえで、その差異分析を月次予実資料に付記し、経営会議及び取締役会に報告する。

2. 差異分析は、売上、原価、粗利、営業利益、配賦後営業利益、営業KPI、事業別KPI、資金繰りその他重要な項目を対象とする。

3. 重要な差異、通期業績見込への影響、資金繰りへの影響又は内部管理上の重要な論点がある場合は、原因、対応方針及び責任者を明確にする。

## 第5章　予算の修正

### 第19条（予算の修正）

年度予算又は事業別予算の執行途中において、経営環境の変化、重要案件の受注又は失注、組織変更、人員計画の変更、投資計画の変更、資金計画の変更その他特別の理由により当初予算を修正する必要が生じた場合、統括責任者は、修正予算案を作成する。

2. 修正予算案は、各部門との調整を経て、経営会議で審議し、重要なものは取締役会の決議により承認する。

### 第20条（予算修正の判断基準）

予算修正の要否は、次の事項を総合的に考慮して判断する。

1. 売上、利益、受注、成約件数又は重要KPIの大幅な乖離
2. 重要な新規案件の受注又は失注
3. 重要なプロジェクトの開始、中止又は延期
4. 法改正、補助金制度変更、外部環境の変化
5. 人員計画、投資計画又は資金計画の重要な変更
6. その他経営判断に重要な影響を与える事項

## 第6章　その他

### 第21条（業績予想の開示及び修正）

当社が上場会社となり、金融商品取引所の規則に基づき業績予想の開示又は修正が必要となる場合、当社は、当該規則及び情報開示に関する社内規程に従い、必要な手続を行う。

2. 上場前又は業績予想開示の対象とならない期間においても、業績見込に重要な変動がある場合は、経営会議及び取締役会に報告する。

### 第22条（保存）

予算、実績、差異分析、修正予算、経営会議資料、取締役会資料及び関連する管理資料は、管理部が保存管理する。

2. 予算管理に関する資料の保存期間は、原則として10年とする。

### 第23条（改廃）

本規程の改廃は、規程管理規程に基づき、取締役会の決議により行う。
