# 予算管理規程（ドラフト）

会社名：株式会社MoMo
制定日：YYYY年MM月DD日
改定日：-
主管部署：管理部
承認機関：取締役会

## 第1章 総則

### 第1条（目的）

本規程は、株式会社MoMoにおける予算の策定、承認、実績管理、差異分析及び予算修正に関する基本事項を定め、経営管理の精度向上と迅速な意思決定を図ることを目的とする。

### 第2条（適用範囲）

会社の年度予算、中期経営計画、事業別予算、月次予実管理及び予算修正に関する事項は、法令、定款その他別に定めるもののほか、本規程による。

## 第2章 予算体系

### 第3条（予算の種類）

会社は、次の予算及び計画を作成する。

1. 中期経営計画
2. 年度予算
3. 事業別予算
4. 月次予算
5. 資金計画
6. 採用計画
7. 投資計画

### 第4条（事業別予算）

事業別予算は、次の事業区分を基本として作成する。

1. AI研修
2. AI伴走
3. OEM
4. AI受託開発
5. SaaS
6. キャリアコーチング
7. その他会社が必要と認める事業

### 第5条（管理資料）

予算管理に使用する管理資料は、全体予算管理資料及び事業別予算管理資料とする。

2. 管理部は、管理資料の保存場所、更新担当、更新期限及び閲覧権限を管理する。

3. 全体予算管理資料は、Dashboard、計画PL、実績PL、予実管理、営業KPI、固定費管理、人件費管理、配賦結果、統合DB_PL及び統合DB_KPIを基本構成とする。

4. 事業別予算管理資料は、事業計画、実績入力、予実管理又は営業予実管理、担当者別KPI、現場登録、出力_PL及び出力_KPIを基本構成とする。

## 第3章 予算策定

### 第6条（策定方針）

年度予算は、代表取締役社長が示す経営方針及び中期経営計画に基づき、管理部が各部門と連携して取りまとめる。

### 第7条（各部門の責任）

各部門は、担当事業又は担当業務に関する売上、原価、人件費、販売費、投資、採用その他必要な予算情報を作成し、管理部へ提出する。

2. 事業別予算を作成する部門は、受注件数、顧客数、単価、稼働数、リセラー数、案件進捗その他事業特性に応じたKPIを併せて設定する。

### 第8条（承認）

年度予算及び中期経営計画は、経営会議で審議したうえで、取締役会の決議により承認する。

2. 事業別予算は、経営会議で審議し、代表取締役社長が承認する。ただし、年度予算又は中期経営計画に重要な影響を与える場合は、取締役会に付議する。

## 第4章 実績管理

### 第9条（月次実績）

管理部は、毎月の売上、原価、経費、営業利益、資金繰りその他必要な実績を取りまとめる。

2. 月次実績は、原則として翌月20日までに管理資料へ反映する。

3. 各部門は、実績入力、現場登録、案件管理、顧客管理その他該当する管理資料に、月次実績及びKPI実績を入力又は報告する。

4. 管理部は、事業別管理資料の出力_PL、出力_KPI及び全体管理資料の統合DB_PL、統合DB_KPIを確認し、全体の月次実績に反映する。

### 第10条（予実差異分析）

管理部は、月次実績と予算を比較し、重要な差異がある場合は、差異の内容、発生原因、対応方針を取りまとめる。

2. 各部門は、担当事業又は担当業務に関する差異分析に協力する。

3. 差異分析は、売上、原価、粗利、営業利益、配賦後営業利益、営業KPI、事業別KPIを対象とする。

### 第11条（報告）

月次実績及び予実差異分析は、経営会議に報告する。

2. 重要な差異、通期業績見込への影響、資金繰りへの影響がある場合は、取締役会に報告する。

3. 経営会議への報告では、全体Dashboard、事業別月次PLサマリー、予実管理、営業KPI及び重要差異の原因・対応策を基本資料とする。

## 第5章 予算修正

### 第12条（予算修正）

年度予算又は事業別予算について重要な変更が見込まれる場合、管理部は、各部門と連携して修正予算案を作成する。

### 第13条（予算修正の判断基準）

予算修正の要否は、次の事項を総合的に考慮して判断する。

1. 売上、利益、受注、成約件数の大幅な乖離
2. 重要な新規案件の受注又は失注
3. 重要なプロジェクトの開始、中止又は延期
4. 法改正、補助金制度変更、外部環境の変化
5. 人員計画、投資計画、資金計画の重要な変更
6. その他経営判断に重要な影響を与える事項

### 第14条（予算修正の承認）

修正予算案は、経営会議で審議したうえで、重要なものは取締役会の決議により承認する。

## 第6章 管理

### 第15条（主管部署）

予算管理の主管部署は、管理部とする。

### 第16条（保存）

予算、実績、差異分析、修正予算、経営会議資料及び取締役会資料は、管理部が保存管理する。

### 第17条（改廃）

本規程の制定、改廃は、取締役会の決議による。

## 附則

本規程は、YYYY年MM月DD日から施行する。
