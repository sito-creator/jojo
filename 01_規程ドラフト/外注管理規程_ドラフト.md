# 外注管理規程（ドラフト）

会社名：株式会社MoMo

施行日：YYYY年MM月DD日

## 第1章　総則

### 第1条（目的）

本規程は、株式会社MoMo（以下「当社」という。）において、社外の法人又は個人に当社業務の一部又は全部を委託する場合の管理体制及び管理方法に関する基本事項を定め、外注の合理的活用により、品質、情報管理、法令遵守及び経営効率の向上に資することを目的とする。

### 第2条（定義）

本規程において外注とは、当社の方針、仕様、指示又は契約に基づき、当社の業務の一部又は全部について、社外の法人又は個人を利用することをいう。

2. 外注には、AI開発、システム開発、デザイン、ライティング、研修支援、営業支援、バックオフィス支援、コンサルティング、業務委託その他会社が外部に委託する業務を含む。

### 第3条（外注の利用基準）

外注の利用は、委託による効果及びリスクを把握したうえで、外部に委託することが適当でないものを除き、次の基準により行う。

1. 当社の設備、能力、専門性、技術又は人員の不足を補完できる場合
2. コストの軽減又は業務効率の向上が図れる場合
3. 当社の作業余力が不足している場合
4. 専門家又は特定スキルを有する者に委託する必要がある場合
5. その他業務上特別の理由がある場合

2. 社内機密、個人情報、顧客情報、ソースコード、AI関連成果物その他重要情報に触れる外注については、委託の必要性、委託範囲、情報管理体制及び契約条件を慎重に確認する。

### 第4条（主管部署）

外注業務の主管部署は、外注を行う担当部門及び管理部とする。

2. 担当部門は、次の業務を行う。

1. 外注の必要性の確認
2. 外注先の調査及び選定
3. 契約条件及び発注内容の整理
4. 外注先への業務指示、進捗管理及び品質管理
5. 検収作業
6. 委託終了時のデータ返却、廃棄及びアクセス権限削除の確認

3. 管理部は、契約、稟議、支払、取引先情報、証憑保存、反社チェックその他管理上必要な事項を支援又は管理する。

### 第5条（外注先情報の管理）

外注先情報は、原則としてNotionで管理する。

2. 外注先情報には、外注先名、担当者、連絡先、委託内容、契約状況、支払条件、反社チェック状況、情報管理上の注意事項、再委託の可否その他必要な情報を記録する。

## 第2章　外注先の選定

### 第6条（外注先の選定基準）

新規外注先の選定においては、次の基準を考慮して行う。

1. 当社の経営方針及び業務目的を理解し、協力関係が保てること
2. 事業内容、実績、専門性又は提供能力が委託業務に適していること
3. 品質、納期、価格、サービス、コミュニケーションその他条件が当社の要求水準に達していること
4. 個人情報、機密情報、顧客情報、ソースコードその他重要情報を取り扱う場合、適切な情報管理体制を有すること
5. 反社会的勢力及び団体との関係を遮断し、社会的信用があること

### 第7条（外注先の定期的な見直し）

既存外注先については、第6条に定める基準を満たしているか、少なくとも年1回又は重要な契約更新時に見直しを行う。

2. 品質不良、納期遅延、情報管理上の不備、契約違反、反社懸念その他重要な問題がある場合、担当部門及び管理部は、継続取引の可否を検討する。

### 第8条（契約書の作成）

外注先と取引を行うにあたっては、原則として契約書、発注書、注文書、業務委託契約書その他委託内容を確認できる書面又は電子記録を作成し、双方又は当社において保管する。

2. 契約書は、原則としてマネーフォワード、電子契約サービス、Notion、Google Driveその他会社が指定する方法により管理する。

### 第9条（外注先の決定）

外注先の決定にあたっては、原則として複数の見積書を取得し、単価、予算、品質、納期、過去実績、専門性、情報管理体制その他必要事項を勘案のうえ外注先を選定し、職務権限規程及び稟議規程に基づき必要な承認を得る。

2. 外注業務の特殊性が高い場合、既存システム又は既存成果物との連続性が必要な場合、緊急性がある場合、少額である場合その他合理的な理由がある場合は、複数見積を省略することができる。

3. 担当部門は、常に原価低減、品質確保及び適正価格での発注に努める。

### 第10条（反社チェック）

新規外注先については、契約締結前に反社会的勢力との関係がないことを確認する。

2. 現時点では反社チェックの実査が未整備であるため、新規外注先、重要外注先及び継続外注先から段階的に確認手続を導入する。

## 第3章　外注管理

### 第11条（契約記載事項）

外注契約には、必要に応じて次の事項を定める。

1. 業務内容
2. 成果物
3. 納期又は履行期間
4. 報酬及び支払条件
5. 検収方法
6. 再委託の可否
7. 秘密保持
8. 個人情報及び情報セキュリティ
9. 知的財産権
10. 反社会的勢力排除条項
11. 契約解除
12. 損害賠償
13. 委託終了時のデータ返却、廃棄及びアクセス権限削除

### 第12条（承認）

10万円以上の外注、継続的な外注、重要な開発業務、個人情報又は機密情報を取り扱う外注、再委託を予定する外注その他重要な外注は、稟議規程に基づき事前承認を得る。

### 第13条（納期管理）

担当部門は、外注先の業務遂行状況、手持作業量、工程進捗、課題及び納期を把握し、納期遅延を防止しなければならない。

2. やむを得ず納期が遅延する場合、担当部門は、速やかに関係部署及び管理部と協議し、対応策を講じる。

### 第14条（品質管理）

担当部門は、必要と認めた場合、外注先の品質管理活動、成果物の品質、レビュー体制、情報管理体制その他外注先の管理状況を確認する。

2. 成果物又は役務提供に不備がある場合、担当部門は、外注先へ修正、再履行、代替対応その他必要な対応を求める。

## 第4章　検収及び支払

### 第15条（物品受入及び成果物確認）

担当部門は、外注先から成果物、納品物、報告書、ソースコード、データ、研修資料その他委託業務の結果を受領した場合、契約書、発注書、仕様書、納品書その他根拠資料と照合し、内容、数量、品質、納期その他条件が合致しているか確認する。

2. 検収は、電磁的記録、Notion、マネーフォワード、メール、検収記録その他事後確認ができる方法により行う。

### 第16条（支払）

検収終了後の支払事務は、担当部門責任者又は承認者の確認を得た請求書に基づき、管理部又は経理担当者が行う。

2. 外注費の支払は、契約書、発注内容、検収結果、請求書その他必要な証憑を確認したうえで行う。

### 第17条（支払条件）

外注代金の支払条件は、契約書、発注書、利用規約、請求書その他取引条件を確認できる資料に基づく。

2. 下請代金支払遅延等防止法その他外注取引に関連する法令の適用がある場合、当社は当該法令に従う。

3. 通常と異なる支払条件、前払、長期契約、自動更新契約その他重要な条件を含む場合、担当部門は、事前に管理部へ共有し、必要な承認を得る。

## 第5章　その他

### 第18条（委託の終了）

担当部門は、委託業務が終了したとき、契約内容及び業務上の必要に応じて、外注先に貸与又は共有した資料、データ、アカウント、ソースコード、顧客情報、個人情報その他会社情報の返却、削除、廃棄又はアクセス権限削除を確認しなければならない。

2. 重要情報を取り扱う外注については、必要に応じて返却確認、廃棄証明、アクセス権限削除記録その他エビデンスを取得又は保存する。

### 第19条（保存）

外注先情報、選定理由、見積書、契約書、発注記録、進捗記録、検収記録、請求書、支払記録、委託終了時の返却・廃棄確認記録その他外注取引に関する資料は、管理部又は担当部門が保存管理する。

2. 外注取引に関する資料の保存期間は、原則として10年とする。ただし、法令又は文書管理規程によりこれより長い保存期間が定められる場合は、当該期間による。

### 第20条（報告）

担当部門は、重要な外注、重大な納期遅延、品質不良、契約違反、情報漏えい、再委託違反、外注先との紛争その他重要事項を経営会議に報告する。

### 第21条（改廃）

本規程の改廃は、規程管理規程に基づき、取締役会の決議により行う。

- 主な外注先及び業務委託先

- 成果物の検収担当者
- 外注費の金額基準
