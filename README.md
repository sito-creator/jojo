# 株式会社MoMo 上場準備資料

株式会社MoMoの上場準備に向けた社内規程、運用台帳、支援会社レビュー資料、初回運用サンプルを管理するリポジトリです。

## 主なフォルダ

- `00_進行管理`：ヒアリングシート、ロードマップ、内部監査計画、Google Sheets確認メモ
- `01_規程ドラフト`：Markdown形式の規程ドラフト
- `02_Word規程ドラフト`：Word形式の規程ドラフト
- `02_Word規程ドラフト_ASCIIファイル名`：文字化け対策用の英字ファイル名版
- `03_運用テンプレート`：運用台帳Excel、議事録・稟議・監査等のWord雛形
- `04_支援会社提出パッケージ`：支援会社レビュー用提出パッケージ
- `05_初回運用サンプル`：初回運用サンプル入り台帳、第1回内部監査手続書・チェックリスト
- `06_機関設計変更`：取締役会設置・監査役設置・定款変更・登記に関するアクションリスト

## 支援会社へ共有する場合

まずは以下を確認してもらう想定です。

1. `04_advisor_review_package_ascii.zip`
2. `06_機関設計変更/Excel/機関設計変更アクションリスト.xlsx`
3. `06_機関設計変更/Word/機関設計変更_支援会社確認メモ.docx`

## 注意

- 本資料は上場準備のためのドラフトです。
- 法務、登記、会計、労務に関する最終判断は、支援会社、司法書士、弁護士、税理士、社労士等の専門家に確認してください。
- ZIP化した資料はMicrosoft/Windows環境での文字化けを避けるため、英字ファイル名版を優先してください。
